# Source through final serialized body

`run/public/UPSTREAM_SOURCE_RECHECK.json` records a fresh read of all five actual source episodes: 813 case×frame entries (727 distinct frames because B04/B05 overlap), 4,848 predicted observations, named pre/post depth profiles and all ten anonymous event depth/quality columns. The recheck reused the prior source auditor only for measurements and image lineage; its old E endpoint-only acceptance is explicitly known false and is replaced by `validate.py`'s independent whitelist checks. No q, reference anchor, depth value, image or candidate was chosen using GT.

`run/public/SOURCE_TO_BODY_AUDIT.json` verifies each new logical request against the immutable old H evidence or the exact old endpoint/image source, complete role and middle token→fact binding, q bound, media SHA, and no native IDs. `run/public/CONTRACT_TESTS.json` includes eight test-only illegal packets whose logical manifest and final body hashes were recomputed to be internally consistent; the semantic validator still rejected stale E history, novel fields, removed/altered depth, wrong fact, future frame and native ID. The real B01 packet passed source→E/H projection→serialized body→synthetic response→canonical parser→complete physical scorer.

After the official Files API uploaded 59 fixed PNGs (55 research, four synthetic), `run/public/BODY_GATE.json` independently checked all 27 actual file-ID bodies, source text, media order and exact bytes. The actual payload hashes were sealed in `run/public/REQUESTS_SEALED.json` before either inference HTTP. The largest body was 357,891 bytes; all 27 total 4,805,559 bytes. Provider file IDs and actual bodies stay in the ignored sender tree.

Poststop `score.py` verified the code/input lock, all logical and actual body hashes, both STARTs, both returned response hashes and ENDs, and the partial seal before opening the exposed retrospective reference. All five fixed new references were scoreable, but no formal call was made. This scoreability does not turn a synthetic smoke into an event-history result.
