# Archive scope and provenance

This archive was assembled from three completed records without making a new API call, replay, training run, or score. It does not modify or resume the stopped Jev validation. The online source was copied read-only from `/home/xiongxiong/deepseek_z4q_closedloop_20260923_side`; its `RESULTS.md` SHA-256 is `3096032d7a19b5292828b887d2ff9803f65f1fe63422298b75e4c8c8c8adc961`. `SOURCE_FREEZE.json` records frozen code and input hashes. The online source repository at run time was `grathball-source/SAM3D-Z4Q-JEV-FishMOT` at `4f2280efbfc3223a9ea5a20da9227d3a235aeada`, copied into the side run. The new repository separates the DeepSeek experiment artifacts from that historical source repository.

`MANIFEST.json` records original and archived SHA-256 hashes. Most files are byte-for-byte copies. Offline `raw_responses/` had HTTP headers removed, and the SLR-2 `REQUESTS.json` image data URIs were replaced with SHA-256 and length placeholders. These transformations are itemized in the manifest. The text, structured numerical evidence, model response bodies, latency, usage, decision traces, source, prompts, and analyses remain available. The original RGB/mask images, videos, source input streams, generated bytecode, and any credential delivery mechanism are deliberately absent from this public archive. The offline source input hashes and online `SOURCE_FREEZE.json` preserve provenance without publishing the raw source media or full upstream observation stream.

The online `requests/` and `responses/` contain the real text-only HTTP payloads and responses; they are not newly generated calls. The offline `raw_responses/` retain the response bodies with transport headers removed. Do not interpret response samples, engineering fixtures, or post-seal GT audits as prospective model accuracy. Both offline stages used exposed events, and the 2,888-frame online segment was also exposed validation. The reported cost is estimated from returned token usage, not a billing invoice.

The frozen online bridge includes legacy `jev-1.13.0` metadata and Jev-style question wording inside the DeepSeek payload. This was actually sent and is therefore preserved as a limitation, while no Jev API response, result, or continued Jev validation is included here.
