## 一个目标与三处工程修复

使质量判断认证实际被比较的深度，并让合法匿名测量参与待决身份关联。固定 whole、原 Birth fixed core、S0 adaptive core 分别绑定真实像素集合、来源索引、原标量、帧与实际身份版本。不能把另一 ROI 的合格证书当作当前标量合格。

身份未确定与测量不可用分开。合并、残片和未决 post 保留测量与真实活动，只禁止认证 A/B 个体 pre/recent_core。一次性出生提案进入事件待决事务，保留真实首次出现时间；不伪造新 birth 或 first_eligible。候选、参考、版本、占用、公开一对一与本地 stage 不合法时保留待决，不先写错误 alias/bank 后改输出。当前帧先决策、提交，再首次发布，不读取未来帧。

缺测合同：D1 whole 为必需主测量；Birth core 为正证据、所需 whole 为反证，逐候选缺失为 UNKNOWN_NO_COMMIT，保留 dummy 和其他完整候选。已测冲突仍按原规则拒绝。S0 不使用 whole，成对 core 不全时所有映射采用共同无信息深度因子，不让某条缺测边自动获利。

## 固定同源六臂

|分支|意义|

|SAM3_NATIVE|原封存 SAM3，全部 mask 与源 ID|

保留原 trigger/q、参考、二维运动、mask、深度权重和候选物理含义；不叠加年龄 ONEFIX、不扩展 PX、不永久锁 ID、不按 GT 调阈值。原 D1_DELAYED/BIRTH_REFINE 仍为原路径。本轮只修其证据入口和状态合同。

工程前缀最多3个本地单线程作业；正式回放最多6个独立本地单线程片段作业，优先启动原始深度投影较重的LW/L3，保持每段内部原帧顺序。CPU线程环境和OpenCV均限制1；无服务器/GPU作业。事实只读共享优化先核对150帧全部科学JSON与预测逐字节等价；身份、候选、bank、alias和pending活动容器仍各分支独立。

## 判定与停止边界

工程通过、输入覆盖与深度收益分层。恢复原 Z4Q 收益属于止损；新深度增量必须比较同源原生、原 Z4Q 和相同接口底座。减少 IDSW 本身不能证明指标提升。MIXED_ORDER−ACTIVITY_ORDER 是组合质量筛选作用；MIXED_ORDER−MIXED_OFF 是冻结顺序因子的条件贡献。

这是重复曝光数据诊断，L3/LW 是未审查预测预标注；不能称独立泛化。深度峰不是鱼身份，宽不确定性不是物理准确率。本轮新关联不读未来；旧保存 SAM3 前端的零未来性未重新认证。失败、无事件和零提交照样交付，并停止该冻结版本，不滚动调到通过。
