# FEEDING 前两段与原始 SAM3 基线的评分与数据核对

2026-09-29。此文是对已封存 `run/` 的独立补充审计。没有修改原预测、请求、响应、seal、`run/METRICS.json` 或数据集，也没有新模型调用。可复现数值见 [`AUDIT.json`](AUDIT.json)，脚本为 [`../baseline_comparison_audit.py`](../baseline_comparison_audit.py)。

## 主结论

**三分支评分代码的主要口径没有发现计算错误，但第二段实验的 SAM3 输入选错了与“2.baseline评测”对应的保存版本。** 原基线正式记录为 `E:/CAU/D-MOT/output/evaluation/sam3_feeding_20260928_v2/REPORT.md`，其第二段 351–555 使用 `ML/segments_v2/resegmented_000351_001906/labels_raw`；已封存三分支的 `prepare.py` 对两段都使用 `ML/labels_raw`。两者同帧 RGB 哈希一致，预测 JSON 在第二段 **205/205 帧**均不同。旧实验仍是对一套真实保存预测的有效回放，但不能与原基线第二段做同源方法比较。

第二段参考标签来自后续人工编辑版本，与原基线的分段重处理预测有很近的来源关系：6240 个参考多边形中，原基线输入有 **5975** 个完全相同几何，三分支使用的旧通用输入只有 **9** 个。因此原基线和参考并不独立；`checked=false`，不能把基线分数当成独立盲测精度，也不能据此定量推断同源性抬高了多少分。这个事实不会使旧输入无效，但要求把输入差异与关联器影响分开报告。

## 验证了什么

- 原 SAM3 基线脚本与 TrackEval CLEAR 源码 SHA-256 和其 `protocol.json` 一致；基线 1471 帧预测与参考输入的有序字节哈希也一致。两段 RGB SHA 与 `AlignedFeeding_v1/manifest.jsonl` 一致，参考 `labels_source` 文件逐帧匹配数据清单 SHA。
- 旧三分支的预测 seal、代码、派生输入和 405 帧发布记录通过原验收函数；本审计使用相同 RLE 掩码与 TrackEval，逐项精确复现 `run/METRICS.json` 中的 B0、B-HOLD、B-VLM 分数。
- 基线在 1920×1080 评分，三分支在 640×360 评分。`labels_640x360` 的所有多边形点逐项符合 `(原坐标+0.5)/3-0.5`，没有错帧或坐标系混用。同一基线输入在 640 网格重算后，单段 IDF1/HOTA 与原 1920 基线相差最多 **0.0365/0.0343** 个百分点；分辨率不是本次主要差异。
- 每个 ID 的多块多边形合并为一张 mask；IoU 阈值 0.5；GT 与预测的两段 ID 均分配不相交命名空间；没有忽略负 ID。拼接后评分与 TrackEval `combine_sequences` 对 IDF1/HOTA/AssA/IDSW/FP/FN 一致。

第二段不同输入使同样 640 网格下原始 SAM3 的 FP/FN 从旧输入的 **148/201** 变为基线输入的 **70/196**，DetA 从 **85.59** 升为 **94.36**。这解释了为什么原基线第二段 HOTA 会显著高于三分支，即使某个分支的 IDF1 更高。两种输入的掩码不同，不能把它们的 HOTA 差额直接归咎于 Z4Q 或 VLM。

## 原基线本身的定位

“2.baseline评测”保存的原 1920×1080 掩码结果为：首段 IDF1/HOTA/AssA **92.9084/91.3582/88.0898**、IDSW **10**、FP/FN **77/144**；第二段为 **79.6864/83.8004/74.4716**、IDSW **28**、FP/FN **74/200**。若改用原基线的分段预测，在同一 640 网格上，SAM3 第二段为 IDF1 **79.7228**、HOTA **83.8347**、AssA **74.4895**、IDSW **28**。两段合并的基线源 SAM3 在 640 网格为 IDF1 **86.2344**、HOTA **87.6345**、AssA **81.2212**、IDSW **38**。这些值只描述**原基线的另一套输入**，不能作为旧 B0/HOLD/VLM 的因果对照。尤其不能因旧 B-VLM 的 IDF1 高于它，就宣称替代基线成功，也不能因 HOTA 低于它，就宣称 VLM 本身造成全部差距。

## 判定与后续

评分实现复现通过；数据来源合同不一致，上一份报告漏列同输入原始 SAM3 行，因而不支持“三分支均优于/均劣于 2.baseline 原始 SAM3”的总括判断。**可保留旧回放内部的 B-VLM−B0 数值增量，但它只是旧通用预标注上的结果。** 要检验原基线分段预测上的三分支效果，需要从该分段预测新建因果输入并重新回放，VLM 必须使用新请求，不能把旧响应套到新状态。此审计未做那次新试验。

复现：在已有 `D-MOT` Python 环境运行 `python experiments/feeding_first_two_s0p/baseline_comparison_audit.py`；读取本地 `AlignedFeeding_v1`、两个保存的 SAM3 预测源、封存的旧实验派生输入与预测，以及上述原基线评测目录。若已有 `AUDIT.json`，脚本逐项验证重算结果相同，不覆盖该文件。
