# DS22冻结实验计划

## 假设与固定数据

原whole/core中位数可能被公共背景平面稀释。使用同帧空间背景相对残差，是否能保留实际差异支持，并为原实际错误边新增深度解释冲突，同时保住正确恢复？可以被“几乎无支持”“正确同样冲突/未知”“错误仍兼容”否定。

全量采用DS21已封存的90次动作：15正确、17错误、58不可评分。主视图180个端点引用，4次Birth另有8个whole视图端点引用；实际共用端点只测一次。标签只在新测量/解释封存后加入。已曝光、L3/LW弱参考，不称独立泛化验证。

原D1实际whole锚点、Birth实际core/whole锚点、q和候选不变。F1390的两种锚点分别为局部138和137，不换锚点。拒绝边没有精确anchor保持UNKNOWN，不推断替代身份。新增测量使用原完整mask的空间支持；这不是声称替换后的表示仍是旧fixed core。

## 唯一自变量与实际常数

唯一自变量是原mask内相对同帧拟合局部背景的深度表示。二维运动、mask、深度源、预测和所有身份/发布事务只读。常数来源为原DS3 CONFIG与DS18 PARAMETERS，实际源代码和有效值随FREEZE封存：

| 参数 | 实际固定值 |
|---|---:|
| 环带内/外半径 | 5/20 px |
| 邻鱼排除边界 | 3 px |
| 背景独立点数/几何覆盖 | ≥64 / ≥0.2 |
| 仿射坐标缩放 | 20 px |
| Huber IRLS轮数/c | 5 / 1.5 |
| 原设计矩阵条件数上限 | 100 |
| 残差尺度下限/质量上限 | 15/60 mm |
| 双侧支持像素阈值 | abs residual > max(30 mm, 3×背景残差尺度) |
| 支持连通性 | 正负分别8连通 |
| 支持独立点数/全mask独立点人口比例 | ≥16 / ≥0.2 |
| 支持残差尺度质量上限 | 60 mm |
| 主边公共尺度/差异门槛 | 30/90 mm |

原source点按row-major一次计数，跨邻mask共用来源排除，背景排除mask及邻mask所有source；投影重复和插值不能扩大人口。mask质量分母是原mask几何面积，背景分母是实际环带面积，支持比例分母是全部独立mask测量点；各分母和邻域移除数量明示。

不做固定7×7腐蚀作为唯一入口，不closing、不填洞，不只保留最近/最大层，不用锚点深度选峰。保留所有正负组件及小、零独立点、噪声大、不合格组件事实。记录背景拟合残差、条件数、mask位置的leverage与模型内预测不确定性；它们不等于物理准确率。环带可能含未检出的鱼或非平面介质。

## 固定比较规则

任一端不可靠或没有合格差异支持时UNKNOWN；不算零代价或安全通过。两端可用时保留所有合格组件对，按相对残差中位数差比较；正负两侧均纳入，不挑最有利组件。只要任一对在90毫米公共门槛内，记录兼容代理；全部对均超出才记录 `DEPTH_EXPLANATION_CONFLICT_PROXY`。

公共90毫米由两端背景、两端支持四个原15毫米floor合成scale30，再乘原sigma factor3得到，冻结后不改。实际四项残差尺度的合成值及其更宽门槛仅附录，不参与主判定，避免宽尺度自动改善兼容数量。这些名义尺度未经物理/身份标定，主冲突也不是不同鱼认证。低于资格的小层可能仍属于真实鱼体，不能据代理直接执行身份veto。

## 必要检查与分析

用真实F159和F905检查来源、薄mask容量和原锚点；不用两例挑参数。数值检查：斜平面、双侧支持、邻鱼、空支持、source去重、共线背景、自洽帧/字段/索引违规、可信投影错位。额外检查全层对、UNKNOWN和固定公共门槛，整体背景平移保持相对结果。

全部端点完成后封存MEASUREMENTS与ACTION_FEATURES，再加入既有物理标量标签。主表同时列正确/错误/不可评分的冲突、兼容、UNKNOWN；端点质量、样本量、残差/支持量、背景拟合失败原因及原深度→相对支持变化另列。Birth副视图单列。原whole/core对照保持原始事实，不按本轮成绩选择较好视图。

可视化固定复用DS21已声明10例及5个缺等级组合，实际主参考/当前两行，显示raw、plane、signed residual和支持；不读q后帧，不用RGB/GT像素。程序重建真实数组，逐项回查封存统计和绑定。独立核验回查全部固定端点及主/副视图，工程可追溯不等于研究成功。

## 资源与结束边界

本地CPU单进程，各数值库1线程；沿用原Python及依赖，不安装、不调用API。启动核对真实内存、磁盘和既有进程；不干扰其他任务。预计200以内独立端点、10张图，输出不到100MB。真实时长、stdout/stderr、退出与源哈希保存。

无新IDF1/HOTA/AssA/IDSW/FP/FN；旧成绩明确单列。本轮不进行状态回放、不改trigger/候选/事务、不自动开展性能试验。若仍没有判别支持，停止该冻结表示；有新证据后另行设计一次原Z4Q自身状态验证。无论结果如何，完整公开产物及HANDOFF更新提交并普通push origin/main，实际核验远端ref及公开字节；旧seal只读、私有像素不进Git。
