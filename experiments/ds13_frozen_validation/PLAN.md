# DS13：冻结R12验证的来源核查

用户“开始”启动DS12的唯一后续计划。审查基点为`4a4c560d85f1e1ef07a497d6ece6bbc25a1931d4`。

## 固定实验

研究问题：DS12曝光开发片段上的小幅收益，能否在新的完整、获准、未调参保存片段复现？按来源与使用记录选最早两段；不按覆盖、事件数、成绩或GT挑输入。

三分支保持`SAM3_NATIVE / F9_RESTORED / R12_RAW`。不改DS12科学代码、实际常数、触发、q、掩码、历史、候选、二维运动、深度测量/打分或事务发布。各分支从独立空状态开始并继续自身状态，保留全部mask，首发布前完成关联。预测和访问封存后，统一评分IDF1/HOTA/AssA/IDSW/FP/FN并核验query/clean/bank/origin来源关系。

主判定冻结为三个率均高于同源native、IDSW不增、至少一次来源一致的新恢复。单次确定性运行不做择优重复；无事件、缺测、fallback、UNKNOWN、零提交和负结果如实保留。F9用于区分共同群组收益和新增出生收益，不设纯几何资格门。该试验不单独识别深度必要性，不证明物理深度准确率。

新增模型HTTP、smoke、训练、SAM3推理、深度补全服务、服务器作业和费用全部0。没有合格输入就记录缺口；不读取sealed test，不把旧四段重跑或换预测源称独立验证。

## 本轮实际执行

只进行了元数据、文件名/存在性、历史用途与科学源码字节核查。`FROZEN_R12_LOCK.json`逐项核验DS12正式FREEZE绑定及实际参数。`OLD_READONLY_LOCK.json`锁定DS1–DS12所有已跟踪文件，旧封存与源码只读。

未选择完整三分支新输入，因此未编写未经输入验证的迁移runner，未运行算法等价回放、源像素合同检查、预测、评分或可视化。新科学结果为`NOT_EVALUATED`，指标与成功判定为`null`。源元数据通过不能当作跟踪工程或模型能力通过。
