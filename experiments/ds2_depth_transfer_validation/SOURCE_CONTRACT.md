# Frozen source and scoring contract

The review base and original DS1 source lock are fixed. The two complete new ranges are selected by the original dataset manifest, existing raw SAM3 prediction files, original aligned depth files and reference **existence only**. DS10–199/351–555 and their owning SAM3 batches/support are excluded. Producer ownership uses the earliest sorted20-frame batch containing a frame, matching the saved postprocessor's first-occurrence rule. Selected support is690–1069 and1200–1906; neither intersects old DS1 support. The shared global-ID stitching job and recording remain dependencies. The cohort is not statistically independent of the recording or a fresh reference annotation campaign.

The dataset's four human annotation work ranges were already exposed in a native baseline protocol; they have no sealed-test designation in the inspected metadata. Current DS2 user instructions authorize development validation of the remaining complete work ranges. Search of this repository's prior experiment/source records found no DS1/depth-association tuning on these ranges; exhaustive external use is UNKNOWN. Other datasets were not borrowed where sensor/grid/fresh-development provenance was unverified. Explicit test directories were excluded without opening contents.

Only original `depth_rgb_640x360/NNNNNN.npz` field **depth_mm** is used. Annotation `instance_id`, repaired v3, annotation ROI, RGB/appearance, future depth and model responses are absent from the predictor. Positive finite pixels define valid depth. Apparent camera-Z millimetres and sensor/alignment calibration limitations are inherited; pixel MAD and WLS scale are proxies, not calibrated physical errors or confidence intervals.

The manager protects pre identities before writing current group evidence. Group and unassigned post stay separate from individual pre depth history. Source/epoch/generation changes and discontinuities break live history; frozen samples come from one preserved qualified fragment. D2 and D3 use identical source selection and frozen functions. D3 changes only WLS scoring mean; it never labels the fitted slope zero.

Full new predictions and evidence/state/transaction/publication streams for **both** segments are sealed before references are opened. Per-frame masks/IDs are checked against the original assignments; first publication is bound to the actual committed/local-fallback mapping. The scorer uses the unchanged TrackEval functions; all detections and IDs remain in evaluation. Pooled scores use disjoint identity namespaces, not averaged percentages.

Physical event diagnosis compares each branch's **actual bank anchors** with q's actual two sources using unique IoU≥0.5 and margin≥0.1. Missing/ambiguous/same-identity references stay UNSCORABLE; local fallback is NOT_STAGED, never a recovery success. Source version and every included pre sample must match a unique physical object for postseal depth residual diagnosis. Only the first contiguous certified same-q-version post fragment within30 frames is used. Such future observations are **POSTSEAL_AUDIT_ONLY**, never event inputs, and raw observation residuals are not physical depth accuracy.

Original SAM3 batching may condition saved front-end predictions on later support within a batch. Therefore **UPSTREAM_LOOKAHEAD_UNKNOWN**, even though DS2's association sees only observations up to the current frame. This experiment is saved-input causal replay, not a claim of live front-end deployment.

Public files contain numeric statistics and frame-local native tokens; private depth, masks and references remain at their actual inventoried local paths. No code, response or seal under DS1/NE1/earlier experiments is rewritten.
