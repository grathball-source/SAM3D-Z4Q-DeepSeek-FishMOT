# Real-pixel visual QA scope

Execution and rendering occurred on the authorized laboratory server, using original RGB files under the authorized V1 dataset, existing predicted RLE masks, depth and appearance streams. Source RGB file hashes were checked against the dataset manifest. The manifest is offset by one global frame; development global frame 1 has no paired RGB, while all 2888 validation frames do. The 24 selected query packets avoid the unpaired first frame. Decoded masks are 640×360 and actual RGB is 1920×1080; the 3× per-axis mapping was measured from metadata, not assumed. All 48 sheets/354 crop rows were generated and validated for source time, frame, image hash, mask area, crop bounds and text legend row order. Mask areas range from 199 to 2034 pixels. Source-grid alignment was independently spot-checked on six development and four validation frames.

Two temporal sheets and their static counterparts (`P04c303d9612421d6`, `P175d295a01799fe5`) were copied into a private, non-repository QA folder and visually examined. They contain real fish in unaltered context and closer RGB crops. Blue/green lighting varies; nearby fish enter several context and close crops, so a clean-looking crop is not an identity oracle. Very elongated target bounds leave white layout gutters (crop aspect ratios across all rows range 0.15–6.92). No mask, text or GT was overpainted on source pixels. The human review is 2 of 24 packets, not exhaustive visual approval of every sheet; automated provenance/geometry checks cover all 48.

FPN appearance is the existing 256-D whole-mask candidate feature (48896/50271 development and 16872/17197 validation observations available); feature `id` disagrees with native observation ID on 7466/6189 rows and was joined by `mask` plus area. The 48-bin RGB histogram is available on 50268/50271 and 17179/17197. The SLR-2 HSV extractor exists in archived code, but HSV descriptors are not present in these streams; no synthetic HSV or replacement ReID was invented. E1 uses the existing RGB histogram for A. Core and whole depth remain distinct in each packet; unavailable history stays empty. `ASSET_INVENTORY.json` contains paths, hashes and source counts. The real sheets are private server artifacts, not public Git files.
