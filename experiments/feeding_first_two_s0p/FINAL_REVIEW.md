# FEEDING 前两段：B0 / B-HOLD / B-VLM，405 帧

## 结论

在 `AlignedFeeding_v1` 的原始帧 **0–199** 与 **351–555** 上，使用已保存的未修改 SAM3 分批预标注作为三个分支的共同前端、投影到 RGB 网格的原始 `depth_mm` 作为深度，分别从空状态运行冻结 Z4Q 控制器。以人工编辑多边形作事后参考，B-VLM 的合并 IDF1/HOTA/AssA 为 **88.6092/85.3061/81.8530**，相对 B0 为 **+1.1666/+0.7827/+1.4902** 个百分点，IDSW **36→35**。B-HOLD 相对 B0 的 IDF1/HOTA 均下降约 0.54 个百分点，IDSW **36→39**。本次模型有可观察增量，集中在第二段两次真实配对提交；它们相对于实际进入前 bank 锚点的 GT 身份都配对正确，数值分支两处都配错。

这是**已曝光、同源修订标注上的离线回放结果**。原始前端是 20 帧一批、5 帧重叠并用 IoU 拼接 ID 的保存预测，**不是原 8400 帧实验的连续 SAM3 会话**。本报告的 B0 是同一冻结 Z4Q `StableReturn` 在这批输入上运行的控制器基线，不可把绝对数值与旧验证/开发序列直接比较。参考 JSON 的 `checked=false` 未被独立改写或人工终验；本结果不是盲测或跨数据集泛化结论。

## 数据、因果边界与实现

- 两段分别编号 1–200、1–205 进入回放，公开结果保留原始帧号；每段新建 B0/HOLD/VLM 三套状态。两段人工 ID 独立，汇总评分给 GT 与预测 ID 都加互不相交的段命名空间。
- `prepare.py` 只读取 `AnnotationFeeding_20260924/ML/labels_raw`、`AlignedFeeding_v1/manifest.jsonl` 和配准深度 NPZ 的 `depth_mm` 列，绝不读取 NPZ 中由标注生成的 `instance_id`。四个抽样原始帧的观测及深度摘要与项目已有 Z4Q 新包适配器逐字段一致；`Bridge.stream` 补入 profile 帧号。
- 原 V4 预测 mask 扫描给出 8/47 个**疑似**触发，不是 8/47 个有效合并—分离。`MergeSplitManagerP` 按原两帧确认、首分离帧决策和 10 秒上限处理。第一段确认 1 个合并、截段前无分离。第二段 B-VLM 确认 8 个合并、6 个到达 q；其中 2 个 q 仍有第三个可见成员残片，属于两成员配对范围外，只走共同事件局部回退。B-HOLD 的自身状态确认 7 个合并、同样 6 个 q。重复帧疑似候选沿用原管理器的“同帧最后一项”选择，并在冻结文件记录数量。
- B0 使用仓库冻结 Z4Q Bridge；B-HOLD 与 B-VLM 共用最新 S0-P 的身份发布和事件局部回退。B-HOLD 在合法 q 使用固定位置/速度/深度权重的数值配对；B-VLM 在合并确认时发 M、合法首分离帧发 S0，仅合法 H1/H2 可改变配对，其他情况同 B-HOLD 回退。第三残片安全门槛是本数据迁移时发现的 2→1→3 范围检查：若把第三残片的临时标签当作完成配对，下一帧会出现 public ID 占用冲突；两分支均跳过该错误提交，不删残片掩码。
- 模型看见原预测 mask 生成的匿名几何图、进入前历史、风险/群组记录、实际单帧 post、质量/深度和程序计算的比较；不发送原 RGB、人工标注、GT raster、未来帧或 native/public ID。新数据的坐标说明明确 depth 为 RGB 相机 Z 方向毫米值，逐帧时间差来自 manifest。当前 q 的 post 速度保持 UNKNOWN。S0 选择经过 stage/commit 后，publisher 才首次写 q 帧；不是实时部署。

## 调用、完整性和复现

共 **13 次官方 `deepseek-flash` 推理 HTTP：9 M + 4 S0**，59 张匿名 mask 几何图走 Files API；13 个 START/END 成对、0 HTTP unknown、0 未发送、0 语义重试。返回 usage 按当前官方 Flash 高峰未命中输入 $0.30/百万、输出 $1.20/百万计算的**费用上界 USD 0.296052**；账户实际扣款可能因时段/缓存更低。13 次模型响应延迟合计约 512.03 秒、中位约 37.44 秒；四个真实 S0 q 的“帧接收到首次发布”约 32.31、50.72、32.61、65.58 秒。同步等待只证明正确顺序，不能称实时性能。

`verify_run.py` 核验两段合计 405 行、每帧唯一 ID、掩码顺序、来源与代码冻结 SHA、publisher 单次写入、每个实际 body/START/response/END/seal 的哈希、S0 响应先于 q 首次发布、以及公开目录无 provider file ID、凭据和 PNG 私有图。真实 B0/HOLD 的全部 405 帧分别与 API 前无模型回放相同；模型改变的仅是 B-VLM 自身状态。关键输出：[`run/VERIFICATION.json`](run/VERIFICATION.json)、[`run/RESPONSE_REFERENCE_AUDIT.json`](run/RESPONSE_REFERENCE_AUDIT.json)、两段各自的 `public/FREEZE.json`、`PREDICTIONS_SEALED.json`、`EVENTS.json`、`CALL_LEDGER.jsonl`、`PUBLISH_LEDGER.jsonl` 和封存预测。早期迁移时一次未完成的无 API 尝试因 2→1→3 残片占用而终止，留在本地 `dry/`，修复后无 API 全段验收留在 `dry_v2/`，均未被当成正式模型成绩。

受限产物的**真实路径、字节数、SHA-256** 及复现依赖在 [`run/RESTRICTED_INVENTORY.json`](run/RESTRICTED_INVENTORY.json)；包含原预测掩码、对齐深度、模型几何 PNG、带 file ID 的 API body/wire 与人工标签位置。Git 只存公开数值、匿名请求/响应文本、预测 ID/哈希、代码与报告，不含密钥、原 RGB、私有 mask PNG、GT raster 或 provider file ID。原数据、旧实验 seal、权重均未覆盖；没有训练或新 SAM3 前端推理。
