## 结论与审计范围

本轮两处深度模型修复没有实现超过同源 SAM3_NATIVE 的目标。D10_RAW 的全部输出与旧 F9_RESTORED 相同；D10_RESTORED 在保留旧两处正确提交的同时，新增 F1027 一次错误交换提交，产生两条新 IDSW。它的 IDSW=108 与原生持平，是“消除两条、又新增两条”，不能解释成没有新增错误。

复盘脚本只读完成封存的 EVENTS、EVENT_AUDIT、METRICS、SWITCH_LEDGER，并核验预测总封存、各段事件摘要、评分摘要和访问封存的 SHA 绑定。包括 90 个分支事件、57 个 q、33 个无 q 事件；三个实际关联分支各 19 个 q，全部纳入，没有按结果挑案例。执行退出 0，记录追加到 EXECUTION_LOG.jsonl。可机读证据在 POSTRUN_REVIEW.json。

本轮目标是超过同源原生跟踪。F9 对比用于解释修改效果，不再设置必须超过纯几何的晋级门槛。

## 3. F1027：新增错误的完整因果链

### 3.1 原生已经正确，错误由此次提交产生

### 3.4 共同 null 到底抵消什么

每个 source 的 null 密度在所有候选完全共享。旧背景对 n137/n95 的 log density 为 −5.121849/−6.968707；新 27 对象等权 KDE 为 −6.097343/−5.755141。新 KDE 包括两个 query，单对象权重 1/27，没有身份筛选或 leaveout。

设同一 source 的前景密度为 f、共同背景为 b，则边 LR 为 `log(.9 f + .1 b) − log b`。H1 与 H2/H0 都关联相同两 source，外面的 `−Σlog b` **精确抵消**；固定先验也抵消。但是 `log(.9 f1 + .1 b) − log(.9 f2 + .1 b)` 内的 b **不会抵消**，它决定不吻合边的背景饱和程度。只有取消 .1 背景混合的另一个模型才会出现纯 foreground ratio；本轮并未运行那个模型。

因此，KDE 是各候选共同 null，不等于 KDE 对交换分数没有影响。本轮同时改 mean/process 与 null，没有 2×2 独立干预，不能把 +2.119396096 的 depth 差变化独占归给某一项，也不能把 F1027 归为“仅均值”或“仅背景”实验证实。

## 6. 有效边界与下一步

新模型确实生效：恢复分支20个角色使用 ROBUST_LOCAL_LEVEL，原始分支19个；各19 q 都具备≥3对象的 KDE，不是由于背景 fallback 未进入新机制。恢复分支预测 scale 中位数86.301，旧F9为166.199；scale 变窄和深度可用次数增加并未带来新的正确提交，反而暴露 F1027 的错误高置信度。
