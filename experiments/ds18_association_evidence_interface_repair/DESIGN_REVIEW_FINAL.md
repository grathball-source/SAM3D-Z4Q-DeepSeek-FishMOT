# DS18 冻结设计与结果解释审查

审查时间：2026-10-03。状态：正式六臂八段已冻结、回放进行中。本文为独立设计审查，未读取正式未封存预测、GT、RGB 或修复深度，未修改冻结代码、参数或输入。没有在这里报告方法结果。使用 experiment-design 技能检查可证伪假设、对照与解释范围。

## 1. 本轮实际上检验什么

目标是让实际参与比较的 whole、原 Birth fixed core、S0 adaptive core 各自获得同 ROI 的质量与来源证明，再检验深度质量筛选和交叉事件内相对深度顺序是否有用。三种 ROI 的像素、有效原始测量、来源索引、统计量和实际帧分别绑定；一处 ROI 合格不能认证另一处的标量。

本轮保留匿名 group/post 的真实测量和活动，但禁止它们给旧 A/B 身份更新个体参考，也禁止它们给其他自动候选充当已认证的个体见证。事件首分离帧先联合选择、stage/commit，再首次发布；待决出生保留真实首次出现、原候选与原窗口。新增模型 HTTP、训练、SAM3 推理、深度恢复与费用均为 0。

这是两个不同的科学问题：

1. **质量问题**：一个标量深度是否代表可用于单体关联的测量人口？混层、共用来源、覆盖不足和过宽尺度可使其 UNKNOWN。
2. **关联问题**：在两条已有鱼的自动短交互事件中，pre 与首分离帧的相对前后顺序能否约束两个身份映射？

测量来源合格只回答第一个问题的工程部分，不是物理鱼身份正确的证明。

## 3. 混层筛选的物理范围

冻结表示将真实有效深度排序，以相邻间隙大于 30 mm 分层；保留全部层与比例、空间摘要和实际来源。显著层至少 16 点、占总体至少 0.2，两显著层的中位差还须大于 `max(30, scale_i + scale_j)`。基础尺度为 `max(15, 1.4826 × MAD)`，原单体尺度上限 60 mm。参数沿用冻结规则，不按结果搜索。

多显著分离层意味着“这个标量存在潜在混合”，不是“已识别两条鱼”。背景、鱼体弯曲、前后表面、投影孔洞边界和同一物理来源重复映射都可能影响分布。该表示没有挑最近层、最大层或某个期望深度作为鱼身份，也没有把被完全遮住的鱼深度编出来。

以下情况仍可能漏检混合：小于 0.2 的污染层、少于 16 个独立有效点的层、连续变化的深度、重叠峰、两个层之间有足够连续测量桥接。单层合格也可能是背景；source 去重能避免重复证据，不能证明表面属于鱼或绝对测量准确。

whole/fixed/adaptive 的筛选会不同。whole 包含原 mask 内全部原标量人口；其共用/污染像素不会在认证原 whole 时偷偷排除。fixed 和 adaptive core 采用各自实际 ROI。应分别统计 `mixture_flag`、source ownership、有效来源覆盖、有效点数、原标量质量与最终 `eligible_single`，允许同一观测有多个失败原因。不能把来源拒绝都叫混层，也不能只看 `valid_fraction=1`。

## 4. “上下顺序”假设的实际含义

这里的上下是相机深度的近/远关系，不是图像 y 坐标，也不是鱼终身固定的深度指纹。它只作用于自动两身份交互事件，使用同帧、同来源版本与实际 public epoch 的合格 pre 配对，以及当前首分离帧。没有 q 后 post 速度或未来帧回填。

短交互期间的物理上下次序也不是普遍不变量：鱼可绕行、改变相对深度或方向；mask 覆盖的可见表面和占比也会改变。即使鱼的真实中心排序没变，whole/core 可见表面的中位排序仍可能改变。模型使用测量不确定性，不能将单体合格进一步等同于“交叉过程中排序必然不变”。

冻结 S0 使用一个成对顺序因子：

`c = p_pre × p_post + (1-p_pre) × (1-p_post)`

`L = (1-0.9)/2 + 0.9 × c`，`logLR = log(L/0.5)`。

pre 置信度来自实际成对差值、已有尺度、真实时间间隔和既有扩散代理；post 来自首分离帧的两份实际 adaptive core。多个历史时刻用于测量摘要，不被当成独立身份投票。`posterior` 是几何与顺序分解假设下的插件候选分数，不是经过校准的真实身份概率。

因为只有一个软因子，单个候选的顺序 LR 在 0.1–1.9 范围内；准入还要求联合赔率达到 9。ORDER 另外要求选中映射有正顺序支持，并优于 lawful H0 的顺序支持。弱但未缺失的 pre 次序也可能形成这一硬准入阻断，既可能避免错误，也可能挡住几何正确动作。若 H0 与候选具有相同顺序信息，顺序不能为改变提供独有支持。

缺测、版本不匹配、断开的历史交集、超龄、旧 pre 符号明确反转等需按实际 `order_evidence.reason` 单列；它们不能被压成“模型觉得不确定”。完整证据缺失时各候选顺序贡献都为 0，并 H0；H0 是保留自身状态，不保证物理正确或安全。

## 5. 缺测与失败机制必须分列

| 路径/机制 | 实际含义与必须检查的日志 |
| --- | --- |
| 无自动事件 | 固定 scanner 未触发或未形成受支持的两身份事件；不能断言录像里没有交互 |
| whole UNKNOWN → D1 | 原必需 query/history whole 不成立，候选边拒绝；其他合法边与 dummy 保留。清洁参考更新也可能停下，但活动保留 |
| fixed core/required whole UNKNOWN → Birth | 逐候选无充分证据提交，原已测反证保留；待决可能窗口内恢复或真实过期。不能把无提交都算保护成功 |
| adaptive core/pre 配对 UNKNOWN → S0 | 所有映射共同中性，H0；必须报告 current 缺失、pre 不足/断裂、版本与时间原因 |
| 潜在混层 | 两显著分离层使单体证据不可归属；与 shared source/稀疏/宽尺度拒绝分开 |
| 顺序与几何相反 | 比较 ORDER/OFF 实际相同首分歧的候选、赔率和 H0；分别计避免错误与阻碍正确 |
| 几何/H0 不支持改变 | 最优 H0、赔率不足、候选物理 mapping 重复；不能算顺序模型失败或成功 |
| 选择后 stage 未提交 | 占用、版本、残片、mask 一致性或局部事务不合法；选择与真实 alias 写入分开 |
| 延期出生已发布 | 真实 `source_previously_published` 与首次出现不变；后来的提交是晚到变更，不是首次持久 ID 发布 |
| 提交后被撤销/冲突 | accepted proposal、当帧发布、durable alias 和后续 native conflict rollback 分开 |
| 已错公共 ID 偶然返回 | public 指标可能改善，但参考物理身份需独立检查；不能称正确身份恢复 |
| 缺少可评分物理参考 | literal endpoint、同版本 pre 共识与事后片段分别标 UNKNOWN/UNSCORABLE；不能填成正确、错误或安全 |
| 首分歧后的状态传播 | 新旧 alias 改变后面的 bank、参考、候选或占用；不能只比较最终 prediction 文件推断局部原因 |

推荐按真实日志形成三个分母：全部观测的测量人口/质量覆盖；全部自动事件及真实自动候选的准入/提交覆盖；有足够参考的物理恢复判定。未知项留在完整分母中，不只报告可判的容易案例。

自动动作至少按 D1_DELAYED / BIRTH_REFINE / S0 分源。分别记录原始选择、matrix 入边、dummy、已测冲突、UNKNOWN、pending、stage、首次发布、实际持久提交与局部回退。D1 的原 15 点 whole/MAD 与实际 EMA、纳入 partner 的贡献绑定需独立核对；来源记录齐备不等于所指物理鱼正确。

## 6. 全段结论的判定框架

- **工程层**：实际 ROI、来源、版本、聚合贡献、匿名隔离、真实 pending、状态克隆与首次发布是否通过。测试通过只支持合同实施。
- **输入层**：whole/fixed/adaptive 的各类有效覆盖；事件输入是否完整；UNKNOWN 是否来自真实缺测/混合/来源，而不是人为删证据。
- **方法层**：完整 IDF1/HOTA/AssA/IDSW/FP/FN 及真实新增/消除切换。IDSW 降低但长段 identity 错配仍可能使 IDF1/AssA 下降，必须同时报告。
- **增量层**：MIXED 相对共享 ACTIVITY 底座和 ORDER/OFF 的实际全段差值；避免错误、阻碍正确、未解决/不可评分分列。恢复原 Z4Q 不能叫新增深度提点。
- **外推层**：数据反复曝光，不能称盲测或独立泛化；同录像新时间段也不等于新录像。L3/LW 的未审查预测预标注提供弱参考一致性，不能与已验收人工物理真值混报。

不存在“大多数未 WRONG 所以安全”规则。UNSCORABLE、UNKNOWN、无提交与局部回退不自动为正例；指标改善也不替代物理恢复正确性的核对。全段结果有效失败则停止当前冻结版本，不能事后改门槛、挑更容易事件或补实验直到提点。
