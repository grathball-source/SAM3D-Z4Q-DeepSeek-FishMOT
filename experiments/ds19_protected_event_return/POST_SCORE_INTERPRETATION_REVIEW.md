## 主判定与证据边界

本轮局部返回机制确实产生了三笔显式提交，但没有证明稳定的正深度增量，也没有在各来源上超过冻结原 Z4Q。L3 两个 RETURN 分支只追平原 Z4Q；Feeding、FishSA 8400/2888、LW 的目标仍未达。此结论依据完整六列预测及既定事后评分，未追加实验或改预测。

`POST_SCORE_INTERPRETATION_REVIEW.json` 保存完整精确指标、独立计算差值、逐切换新增/消除、紧凑真实发布/确认轨迹和输入 SHA。JSON SHA256：`a2807cf9347576264ae3ee1d4a0ff1ef885f04ad6d6a5a8bfbdaded6046eeac3`。

八段六列的 IDSW 均与 SWITCHES 条数相等；所有来源的六列 FP/FN 相同。Feeding pooled 的 IDSW/FP/FN 与四个独立片段的计数总和一致，未把其他数据集混入汇总。

评分来源记录为全部预测 seal/科学来源核验后才开放参考；masked/ignored IDs=0，GT_used_for_predictions=false。审查仅读取公开评分派生记录、封存预测与冻结控制流，没有直接读取 GT/raster。

## 零显式提交也可能改变发布

Feeding 0–199 的 ACTIVITY_RETURN 没有显式 local_return，但 private proposal 的未接受确认会改变主 pending：

1. MS1-F155，local193/global192，native38 的保护候选 public16/count1 被 carry 到主 pending；这覆盖普通路线 public7 的3次确认。
2. local194 普通候选7重置为1次。local195/global194，ACTIVITY_ORDER 普通D1达到5次、accept38→7；ACTIVITY_RETURN仅2次，首次发布仍为38。
3. local195–200共有6帧发布差异。该段HOTA增加0.031170542百分点；Feeding pooled增加0.004820606百分点，而IDF1与IDSW均不变。

这是未接受保护候选与普通候选的确认竞争效应，不是一次显式局部恢复成功，也不能记作 MIXED 深度收益。冻结控制器 `preview` 写回 `baseline.engine.pending[native]` 的真实路径与封存 trace 对得上。

LW MIXED_RETURN 同样显式return=0：local949–952把native32→保护public7的count1→4写回pending，普通public24反复重置。MIXED_ORDER在local952接受32→24，MIXED_RETURN到957才在普通D1接受24；952–956共5帧首次发布不同，但完整指标全部相等。

切换按 `(scorer global frame, reference gt_id)` 分别记录新增、消除；同一参考/帧仅public标签改变另外列出。净差不代表只有同样数量的新错误。

- L3 两个 RETURN 相对各自 ORDER 各新增1次：global3024，弱参考id6，public47→9；没有消除。IDSW从1升到2，同时IDF1/HOTA/AssA升高，且完全等于冻结原Z4Q。不能通过隐藏这次真实返回切换声称IDSW改善。
- LW ACTIVITY_RETURN 相对 ACTIVITY_ORDER 消除1次：global3427，弱参考id1，native150，public150→144；没有新增。IDSW9→8是实际计数变化，该局部144→133仍不可评分。
