# DS31 V2 深度方法静态审查

本稿只依据当前冻结的 `depth.py`、`identity.py`、`CONFIG.json`、`PLAN.md` 及实际调用的 DS1 `depth_state.py`。写稿时完整八段运行进行中，尚未读取指标、GT、预测病例或物理对应结论。以下是代码事实与可检验机制假设，不是效果结果；主报告应在全部预测封存和独立评分后补入实际计数。

## 借鉴的有效结构

持久 PID 与 SAM3 native/source generation 分离。清楚、连续且已确认的来源沿用当前分支 PID；新生、重现、接触释放或分离观测联合竞争未占用的旧 PID。原 native 整数相等不具有额外身份优先权。每行保留 dummy，使用 Hungarian 全局匹配及删边后代价间隔；通过后先提交，再首次发布。两条新臂各自延续真实状态，`PID_DEPTH−PID_MOTION` 是本轮深度增量的主要比较。

运动使用最近最多10个连续 clean 观测的真实时间 OLS、160 px/s 速度裁剪和最多1秒平移外推；几何成本为 `0.6×(1−mask IoU)+0.4×min(1,distance/radius)`。搜索半径以32 px、物体尺度和80 px/s增长项组成，增长最多1.5秒，身份参考最多12秒。零 IoU 在运动范围内仍可能成为候选，但深度不能重开已被几何或 clean 规则排除的边。

合并可疑事件一出现即保护全部成员 PID。V2 把这些 PID 排除出普通关联候选，并逐帧核查真实 member bank 哈希不变；GROUP、未接受的临时 post 映射不写旧个体 clean 历史。取消、超时或首次联合分离后才释放。保护完整参考与给当前可见掩码保留一对一输出同时进行，不生成不可见鱼体。

## 当前实际深度规则

量测固定使用封存 DS18 的 **adaptive exclusive core 独立 native 来源总体**：`core.summary.median/MAD`，不是原对齐像素重复加权的 `inclusive_summary`，也不是某个有利层峰。保留同 ROI、原来源、证书和 fact 引用。有效要求 core 的 single/quality/source ownership 条件成立、未验证来源为0、独立点数≥16、占原几何 core 面积比例≥0.2、正的有限中位数、有限非负 MAD，且 `max(15,1.4826×MAD)≤60 mm`。whole 或 core 任一出现 mixture 标记或超过一个 substantial layer，均阻止个体深度写入；whole 不替代缺失 core。

每 PID 保留最近30点的连续片段，拟合取末10点；断帧、时间不递增、来源/PID版本改变、缺测或风险不会被删点后拼接。最新完成的可靠片段可继续预测，但最后观测超过12秒即为 null。当前 q 测量在选择后才可能进入新片段。这里的深度是表观 RGB 相机 Z，单位 mm；15/60 mm 是既有工程尺度，未获水下物理精度或置信区间认证。

DS1 原函数在真实时间上执行 WLS，深度斜率不裁剪、不改写。令 `σᵢ=max(15,1.4826 MADᵢ)`、`τᵢ=tᵢ−t_last`、`Xᵢ=[1,τᵢ]`、`W=diag(σᵢ⁻²)`、`Δ=t_q−t_last`、`h=[1,Δ]`：

\[
\hat\beta=(X^T W X)^{-1}X^T W z,\qquad
\mu_q=h\hat\beta,
\]

\[
s_q^2=\gamma h(X^T W X)^{-1}h^T
+15^2\left[1+(\Delta/t_0)^2\right],\qquad
\gamma=\max\left(1,\frac{\sum_i[(z_i-X_i\hat\beta)/\sigma_i]^2}{\max(n-2,1)}\right).
\]

多点的 `t₀=max(片段时间跨度,相邻正时间间隔中位数)`。不足3点或拟合退化时使用最后实测值，斜率 UNKNOWN，尺度为 `√{σ_last²+15²[1+(Δ/t₀)²]}`；单点没有额外采样间隔信息时原函数采用1/30秒。深度按完整 Δ 外推，并没有运动分支的1秒截断。

只有几何最优与次优代价（包括 dummy）的间隔≤0.3，深度才进入该行。当前量测、共同背景或任一**当前可行 PID**的预测缺失，就把该行所有深度成本设为精确0。候选缺深度不会获得相对有信息候选的零成本优势。

对可用行，观测尺度 `s_obs=max(15,1.4826 MAD_obs)`，信号尺度 `S_k=√(s_q,k²+s_obs²)`；背景取同帧全图中位数和 `S_bg=max(60,1.4826 MAD_full)`。使用4自由度的归一化 Student-t：

\[
\ell(z;\mu,S)=C-\log S-2.5\log\left[1+\frac{(z-\mu)^2}{4S^2}\right],
\]

\[
c_{d,k}=-\log\{0.9\exp[\ell(z;\mu_{q,k},S_k)-\ell(z;\mu_{bg},S_{bg})]+0.1\},
\qquad c_k=c_{geometry,k}+0.25c_{d,k}.
\]

`−log S` 保留密度归一化，大尺度不会仅靠标准化残差变小而自动获利；0.1共同污染项限制极差信号的惩罚。可用但宽泛的预测并不自动变为0。dummy仍为1，硬几何可行性和0.15全局间隔不随深度改变。单个可行 PID 也可能与 dummy 竞争，故“深度改变选择”必须区分旧 PID 间换选和 PID 对 dummy 的录用变化。

## 相对提案的范围与差异

本轮实现了持续身份、因果运动、可靠区域的动态 Z 与合并期间参考保护；实际量测采用严格 core 和 whole 风险审核，没有 whole/core 自适应择优、层对应认证或物理鱼体重建。**没有永久近/远身份不变量**：不同 PID 的预测 Z 可以交叉，不能用历史近远顺序给鱼编号。

本轮沿用保存的 SAM3 掩码，仅新增身份层；没有颜色、外观、光流、掩码拆分、未来帧回填、双向平滑或 SAM3 内部记忆修改。保存的批次前端也不能被声称为已验证的零前视在线 SAM3。普通 source 的新 PID 建立条件在代码中是至少5次 clean 且出生后至少6秒（首帧来源免6秒条件）；这段期间继续尝试旧 PID 关联，并不是6秒后禁止关联。

首次分离 q 还要求至少两个当前 clear、运动可行且面积达旧最小面积0.6倍的候选，并与最近组掩码有≥0.15的归一化可见重叠。原残余掩码占用成员 PID 时该目标仍不可匹配；事件释放不等于身份已恢复。取消条件是下一帧 donor 面积恢复到旧面积的0.5倍，超时为10秒。

## 预期失败机制及封存后检验

| 可检验机制假设 | 需要查看的既有输出 | 什么观察会削弱或否定该解释 |
| --- | --- | --- |
| 严格 core/whole 审核、短片段或一个弱候选使整行深度长期 null，未触及身份机会。 | `DEPTH_EXTRACTS` 可用比例/失效原因；`TRANSACTIONS.depth_rows` 当前/历史缺失、active数和真正 PID 改变数。 | 多个真实身份机会拥有完整可用行且产生实际提交，则不能用“深度始终没进入”解释该批结果。 |
| 正常运动或错误持续 PID 被锁定，歧义行未开放；真候选被 clean/搜索/占用限制排除，深度无法救回。 | unlocked/candidate/feasible矩阵、同状态几何选择、占用记录；封存后已有切换与动作参考审计。 | 目标旧 PID 实际可行、未占用且参与联合匹配时，相关失败必须改查成本或参考，不能归于无候选。 |
| 短期线性 Z 外推遇到快速转弯、姿态/可见表面改变或长 gap；代理尺度不足以描述非线性。 | WLS斜率、残差、gap、scale、当前观测与四度t密度；结合封存后动作参考关系。 | 实际错误边仍有小残差、短 gap，正确物理对应的预测也可靠，则线性外推失配不是充分解释。 |
| 单层、来源独占只能认证量测总体；旧 PID 已反转或 core 量到稳定背景，错误参考会被持续保存。 | fact/ROI/source引用；原始发布与动作 anchor；封存后物理参考/连续片段一致性。 | 参考与当前物理对应被独立确认清楚且正确，却仍关联失败，则需查看几何/密度而非单独归咎旧参考污染。 |
| full-frame背景与固定dummy的相对密度尺度改变录用，而非真正分清两个旧身份；几何与深度可能相冲突。 | active行每边 signal/background/raw cost；`geometry_selected_target`、真实target、margin、mapping_changed。 | 深度真实改变多个 PID 间选择，正确物理边得到更高相对密度且整段保持，才支持身份判别增量。 |
| 合并被取消、未满足可见分离条件、超时或残余占用，保护后的成员没有可提交窗口。 | `EVENTS`终态、group records、first split、occupied member targets、protected pins。 | 出现有效 q、两个旧目标均未占用并实际提交时，这一解释不适用于该事件；保护hash变化属于工程合同失败。 |

这些解释只用于核对冻结方法，不能作为本轮滚动改参数或选择有利病例的依据。深度 active、重复接受同一 PID、真实 PID 改变、同状态几何换选、两独立臂后续分歧须分别计数；指标增益与物理对应正确也须分别审查。L3/LW 弱预标注、曝光数据复用和不完整内部历史日志限制均应保留，不能把预测一致性写成身份真值。
