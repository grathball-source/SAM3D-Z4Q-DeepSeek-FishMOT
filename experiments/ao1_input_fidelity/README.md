# AO1 input-fidelity diagnostic — exposed cases, no model calls

Read [RESULTS.md](RESULTS.md), [DECISION.md](DECISION.md) and [PROTOCOL.md](PROTOCOL.md) before interpreting any packet. `SOURCE_MANIFEST.json` and `SCORE_KEY.json` are research records **not for blind reviewer distribution**. Only one opaque case/version folder from the private `range_corrected_run/blind/` tree may be supplied for a first judgment. [BLIND_STATUS.json](BLIND_STATUS.json) records that no independent judgment has yet occurred.

The executable order was `build_input.py --pilot` → `build_full.py` → `numeric_full.py` → `parity_check.py` → `test_ao1.py` → `make_artifact_manifest.py`. Exact arguments, source paths, stdout/stderr, failed preparations, exit codes and authoritative run are in [EXECUTION_LOG.md](EXECUTION_LOG.md) and [RUN_RECORD.json](RUN_RECORD.json). All scripts use already installed Python/OpenCV/pycocotools and do not call models or read GT raster. Run on the authorized lab host after current resource/path checks; do not copy raw pixels to Git. V0 old media and all other sealed results are read-only.

The authoritative public records at this directory root correspond to `range_corrected_run`. `pre_cutoff_guard_run/`, `pre_range_fix_run/` and `preliminary_inventory/` preserve earlier AO1 outputs and explicit corrections, not alternative selected results. The large private media (and every older private attempt) remain in locations with size/SHA-256 in [ARTIFACT_MANIFEST.json](ARTIFACT_MANIFEST.json). The root repository `MANIFEST.json` only covers the old packaged archive, not this extension.
