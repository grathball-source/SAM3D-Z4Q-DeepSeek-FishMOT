# DS1–DS6 计分、原生身份恢复目标与下一轮冻结建议

## 1. 结论需要修正的前提

“深度从未超过 native”不符合旧结果。DS1 在已曝光的 405 帧上 D2 相对 native 的 IDF1/HOTA/AssA 为 +0.7900/+0.3817/+0.7203 个百分点，IDSW 同为 32。DS2 的新 1066 帧没有复现该优势；DS6 合并固定四段 1471 帧后 D2 仍低于 native，新 D5 与 D0/D4 每帧完全相同。应写成“DS1 局部开发优势没有在后续片段和全量组合中保持”。

|试验|实际检验对象|可以支持的结论|
|---|---|---|
|DS1|405 帧的真实数值事件闭环|组合模块在该曝光范围改善；两次深度选择避免了底座强制错误交换；WLS 独立贡献未证实|
|DS2|另 1066 帧，未改 DS1 参数|D2=D0=D3；相对 native 退化；共用底座新增错误超过共同正确恢复|
|DS3|轮廓内采样占用代理|测量假设 FAIL；99.62% core 纯度下再增 10pp 不可达到，也不能检验轮廓内部物理表面|
|DS4|固定 Q/R 的原始轮廓深度共识|PROXY_GAIN_ONLY；F6 增兼容、减冲突，同时扩采非匹配点；没有跟踪成绩|
|DS5|匿名深度片段与固定平移诊断|AUDIT_COMPLETE；不能认证表面或标定；最大簇有兼容率损失|
|DS6|1471 帧完整五分支闭环|FROZEN_SUPPORT_RULE_NOT_MET；工程成功，多片表示实际选择增量 0|
|归档 v3|405 帧旧 Z4Q 的标签辅助、前后帧修复输入|弱曝光诊断；旧 Z4Q IDSW 36→35，但仍低于同源 native；不能当纯因果深度收益|

这不是计分器删掉了深度收益。DS6 的原生、几何、旧 core 分支逐帧精确复现，负 ID 保留，每段身份隔离，官方 pooled 由全部帧直接评分。FP/FN 不变与原 mask 完整保留一致；HOTA 的 DetA 微差来自身份相关匹配，不能据此声称 mask 变化。

## 2. 当前事件到底能纠正什么

独立从 DS6 的实际 bank anchor/post 匹配记录重算原生 pair：`native={source:source}`，与该事件的参考期望映射比较。这里“原生一致/不同”仅指实际 bank 的 RGB 身份对应，不是完整录像的独立物理身份认证。

### D5 的全部 18 个 q

- 4 个无法形成参考双射，均 fallback：F398/F434/F1280/F1504。
- 9 个期望映射与 native pair 一致：3 个接受正确（F415/F787/F1039），5 个接受错误（F419/F519/F1027/F1263/F1719），1 个 fallback 首发正确（F1359）。
- 5 个期望映射不同于 native pair，均接受正确：F470/F764/F1239/F1390/F1745。它们是现有两个旧目标候选可以表达的原生碎片重接机会，属于共同恢复机制；D5 在它们上没有相对 D0 的新增输出贡献。

D2 的 18 个 q 则把上述 5 次错误中的 F419/F519 改成正确，留下 3 次错误。DS1 的两个深度增量主要保护原生对应，不能都命名为“修复 SAM3 原生错误”。真正重接机会、保护 native、控制器自行引入的交换必须分开计数。

DS6 原生 CLEAR IDSW 共 108。仅 7 条位于 D5 的 q 同帧，其中 6 条发生在该事件两个 post source 上；另 1 条是 F470 的事件外 n:81。101 条在其他帧。这只是覆盖诊断：早期状态操作可影响后续切换，因此不能把 101 条直接判为永久不可纠正，也不能把 7 条当作独立恢复机会或 IDF1 收益上限。固定原 mask 的双成员恢复无法补出漏检鱼、把合并 mask 拆成两个检测，或覆盖所有没有合法 q 的原生身份失败。

## 3. `COMMIT` 与 `RESOLVE_NO_ID_CHANGE` 的实际含义

`merge_split_manager.py::stage_group_restore` 的 `changes` 比较的是 **当前 q 内部 preview 的 mapping**，不是 native，也不是上一公开帧。q 进入 preview 前已通过 `temporary_numeric/choice_mapping` 生成一组暂定旧目标映射；S0-P 的 `OutputIdentityPolicy.apply` 在 q 直接允许该 provisional 映射进入 preview。

因此，最终选择与 preview 一致会记为 `RESOLVE_NO_ID_CHANGE`，但 stage 仍然更新 alias、bank、anchor 等身份状态，并可能首次公开与 native 不同的对应。它不代表没有身份事务，也不代表没有公开身份变化。DS6 五个 D5 WRONG 全部属于这个状态；只对 `COMMIT` 加质量门会漏掉全部五次错误。

|分支|接受参考正确|其中相对 preview 有差异的 COMMIT|其中与 preview 一致的 resolve|接受参考错误|fallback|
|---|---:|---:|---:|---:|---:|
|D0/D4/D5|8|1|7|5|5|
|D2|10|3|7|3|5|

“1 次 COMMIT”只能称 1 次 **改变内部 preview** 的事务，不能用它单独计量对 native 的有效修复次数。“8 次正确”只能称 8 次接受映射与事件 RGB 身份参考一致，不能称 8 次新恢复或 8 次深度收益。

下一轮每个 q 都应冻结并记录：原生 mapping、本支进入 q 前的 last-public/source version、内部 preview mapping、决策所选 mapping、实际首次公开 mapping、alias/bank/epoch 写集合。分别报告相对 native、相对 last-public、相对 preview 的改变。

## 4. 参考风险与成功分类边界

1. 人工 RGB polygon 的 IoU≥0.5、margin≥0.1 是身份对应的资格约定，不是深度 surface 标签。actual-bank anchor 比虚构的起始 ID 参照更可靠，但仍可能陈旧、被前序错误污染、与当前 pre 身份不同。缺锚、共享 GT、无双射、pre 不同、版本变更应单列保留。
2. DS4 的 R 共识来自原始深度，能与错误测量共享 12m 异常；F1319 的兼容反例不能证明物理准确。F1385 全部选点位于 other-fish 却仍兼容，证明数值接近也不能认证身份。
3. DS6 主 outcome 中 `NOT_STAGED` 优先于参考资格：各支 5 次 fallback 包含 4 次首次公开不可评分和 1 次首次公开正确。主表不可评分=0 并不等于 18 个 q 都可评分。把“执行状态×参考资格×首次公开正确性”作为三个独立列，避免相互遮盖。
4. 18 个 q、36 个角色、同帧多个像素、状态延续的数百帧、ledger 差集条数不是独立重复试验。率必须使用固定全量分母，并保留 UNCONFIRMED/NO_SPLIT/UNKNOWN。不得根据成功接受集或 GT 重新选择事件。
5. DS6 的 5 个 joint 可用 q 全部只有单个合格片的 post；2 个真正 multiple-qualified-current q 都缺 joint，故多片表示增量 0 的识别范围很窄。它没有有效检验“多片歧义如何被历史消解”。
6. 归档 v3 没有成为纯无 GT 输入：5 个 annotation-assisted 像素归零不改输出，但基础修复仍使用前后帧。两个取消恢复的 GT 关系 UNKNOWN，四个已核验错误恢复仍发生。0 veto 也主要受来源片段/目标谱系资格阻断，不能证明逐边检验有效。

## 5. 下一轮最小冻结设计建议

### 主问题

测试“在原生连续身份已可保持时，不强制接受旧目标交换；在真实新碎片上，使用可辨识深度证据进行受控接回”。成功必须来自真实状态与首次公开输出，不能只把已生成的结果行改回 native。

### 控制范围

继续固定全部四段 1471 帧、全部原 mask、同源时间、scan/trigger/q、二维项、F6 参数、片段资格、历史版本与权重；旧 DS1–DS6 全只读。该范围是曝光开发回放，不能改名为盲测。每个分支从各段空状态独立运行；全部分支封存后统一打开原人工参考；评分器保留负 ID、固定 frame coverage 和段间身份隔离。

### 建议受控因素

- **发布/接回政策**：现有强制 H1/H2 恢复与几何回退，对照显式 native-continuation/no-attachment/abstain 路径。未确认身份时不把某个旧 ID 强塞给 post。保护必须作用于 q 的 preview、stage、bank/alias 和首次 publisher，不能只限制 `COMMIT` 标签。
- **缺测处理**：原四边 joint，对照候选共同的可比部分证据。一个 post 可用时，至少应明确该 post 对 A/B 的两条边是否可比较；缺测项在所有候选采用同一边际化规则并记录可用性。不能只删坏边后平均剩余边，也不能给可用较少的候选隐含奖励。

以这两个因素构成一次 2×2 可以分解缺测门与原生保护的作用；保留同源 native 及精确复现旧 D5 作为必要基线，旧 core D2 作为参考。不要同时重新选择 F6 floor、history n、30mm 图、权重、warp 或采样方式。具体因果门与概率假设由 root 在运行前明确冻结，本审查不凭已知 GT 选择数值门槛。

重要限制：如果“可比部分证据”要求两个角色 forecast，F419 的 B 缺历史、F519 的 A 缺历史仍不满足。因此仅放开 post 的 all-four 门不能保证恢复 DS1 两次正确翻转。若允许单历史对完全 UNKNOWN 的另角色比较，必须声明该缺测生成模型假设；它可以提供反对某条边的证据，不能把无信息替代候选命名为正向身份确认。深度无信息时，回原几何会保留原来的五次额外交换；保留原生与回几何是不同策略。

在 DS6 既有 D5 状态上，候选共同的“两个 forecast＋至少一个可用 post”仅新增 F415/F1027/F1239 三个可比 q：分别是正确保持 native、错误交换 native、正确接回新碎片。连同原 5 个 joint，合计 8 个；其他 8 个可计分 q 缺角色历史，2 个无数值 pair。它是预先已曝光的机制诊断，不能作为下一轮允许执行的 GT 白名单。

native-continuation 路径也不能每帧把本支 ID 重置成 source 数字，否则会撤销已经合法接回的旧身份。应按已冻结的 native/source generation、public/epoch 维护因果延续，保留合法旧重接；占用冲突使用显式未解身份并保持同帧一对一。新 source 不自动等同旧鱼，连续 source 也不能被事后 GT 认证成正确。

### 冻结前必要检查

合成已知身份检查覆盖：native 已正确却几何想交换；真实 source 重生需接回；无正向身份信息；单 post 缺测；单角色历史缺测；近似等深度；多个匿名片；目标 ID 被事件外鱼占用；visible residual 阻止原 pair；failed preview 原子性；过期版本；未来数据扰动；原 mask 与负 ID 完整保留。测试结果不能代替真实数据收益。

### 评价与停止规则

继续使用 DS6 已冻结的完整 IDF1/HOTA/AssA 与 IDSW 主判定，附 FP/FN、分段表与真实作用范围，不另设取悦已知病例的新阈值。相对 native、旧 D5、受控缺测对照分别计算全段增量；同状态 shadow 只解释局部选择，不能替代独立状态闭环。

事后固定参考审计应分别统计：native-pair 原已一致且被改错、native-pair 不同且正确接回、正确保持、错误保持、事务阻断、参考不可评分、无 q、上游检测不可恢复。真正原生修复的事件需对应 actual-bank 身份参考，并追踪首次发布及持续范围；避免控制器自行引入的损害另列。任何 UNKNOWN/fallback/无输出差异都不能记作恢复成功。

目前证据能支持冻结针对性工程修复和再试验，不能支持深度物理准确、完整原生错误可纠正、独立泛化或统计显著性。一次正式运行之后完整报告失败与弃权；不在相同 GT 上滚动换阈值直到超过 native。
