# M1 frozen real-VLM pilot

Review base `bdf1ba5a1406be136fb65acd085592503e35865c`. Five exposed AO1 cases, one AO0 recoverability positive and the same four old harmful E1 negatives. This is an offline model-capability falsification probe, not a new tracker intervention or blind generalization result. No numeric D/A/M scores, old answers, GT, baseline labels, repository text or current chat are in model messages.

P0 sends the old V0 sheets with independent static/temporal legends, or AO0 fish-grid/interaction legends. P1 sends only exact same-frame original-resolution matched crops/contact crops; no extra whole image or outline. P2 adds the entire unchanged pre-query fixed-coordinate full-frame window to P1; it is a combined context-plus-temporal contrast, not pure time. Each supplied image has its own ID and tile/role/relative-time legend. Images and options are frozen before any research response. One frozen system prompt is in `PROMPT.txt` after preparation.

The 30 research calls are 15 first P0/P1/P2 choices, five unchanged P2 repeats, five P2 C1/C2 name/order permutations, and five P2 image-off controls. A fixed seed shuffles cases within the first/diagnostic rounds; diagnostics cannot replace first decisions. Technical image smoke is capped at two, inference HTTP at 32, peak-price worst-case reserve at USD 5. No failed/uncertain research call is retried, omitted, or replaced. The answer-free sender runs inside a filesystem bubble containing only this private run, its exact media, request plan, and sender code; it does not mount the repository or AO1 score key.

Only after all inference outputs are sealed does a separate scorer read the exposed-case `SCORE_KEY.json`. Transport, bound choice, cited-image format, still-unknown visual semantics, and identity correctness are separate axes. An `INSUFFICIENT` choice is an abstention, not a correct answer. Long explanations or invalid evidence do not silently rewrite an explicit choice to B0. Repeat/permutation never vote. No offline choice is converted into new IDF1/HOTA.

Frozen advancement rule: technical completion requires all 15 first choices usable and at least 95% bound decisions across 30 research/diagnostic calls. Tentative single-event signal additionally requires B01's first P2 rescue to survive repeat/permutation, no first P2 harmful change on B02–B05, and actual-image citations. Even then model/method generalization and E2 remain unproven. If validity or stability fails, report the appropriate engineering failure or inconclusive status; do not retune this cohort.
