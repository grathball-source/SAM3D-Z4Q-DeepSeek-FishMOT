# Observation lineage and time contract

`lineage_audit.py` examined all intervening prediction/observation frames between the sampled current frames in all 24 old E1 packets, without GT. Across 48 current segments, it found **0 native disappearance gaps**, **0 B0 public-ID switches**, and **17 contact/neighborhood transitions**. Thus a cross-disappearance or cross-ID splice is a real unguarded code path but was **not observed** in these 24 old sampled segments. Do not claim that it caused the four old model errors. The old packet builder (`build_packets.py:119-127`) samples query−14/query−7/query when a native exists, without asserting intervening continuity; the old validator (`e1_protocol.py:24-39`) checks only times/domain.

The new `contract.py:12-24` requires stable `(sequence, native_id, tracklet_epoch)` across a node, unique `(sequence, frame, native_id, mask_key)` observations, explicit continuity certification and causal timestamps. Contact-contaminated samples are excluded from D/A/M in `edge`, and missing modalities are explicit. These rules passed synthetic checks, but the A-stage probe did **not** create real E1C packet nodes with these fields, so actual E1C input coverage remains blocked. Epoch metadata in `probe.py` is diagnostic only and is not a substitute for whole-stream continuity certification.

The old 256-D FPN feature was available in the source but old E1's numerical A used the 48-bin RGB histogram; FPN availability is **not** evidence that FPN participated in the model or N comparison. No new HSV/ReID feature was fabricated.
