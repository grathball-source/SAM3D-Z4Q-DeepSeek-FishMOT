# DS1 input and identity contract

Fixed start: `2fe9e0c8eb497432ae5e4c676f09b8d67bff9474`, verified against live origin/main on 2026-09-30. The experiment uses SOURCE_OLD saved SAM3 polygons, original frames 0–199 and 351–555 (405 frames), with independent segment identity namespaces and empty state at each start. The saved batches are not evidence of an online SAM3 frontend with zero lookahead.

Actual local input is `E:/CAU/D-MOT/data/AlignedFeeding_v1/depth_rgb_640x360/NNNNNN.npz`, field **depth_mm only**. The original NPZ also contains annotation-derived instance_id; it is not read. The aligned raw plane is float32, shape 360×640, RGB-camera Z in millimetres. The native raw source is 640×576. Dataset README and calibration.json document a 1 mm SDK playback scale, Brown–Conrady undistortion, depth-to-RGB extrinsics, and nearest RGB-camera Z buffering. Raw RGB is 1920×1080; polygon inputs were resized to 640×360 using the existing pixel-centre rule. DS1 reuses that exact grid and does not reproject or fill holes. Source originals, prepared streams and per-file byte/SHA records are checked before formal prediction.

Depth is named **APPARENT_CAMERA_Z_MM**. Device model, physical sensing method, underwater refraction calibration, residual alignment accuracy and absolute fish-depth accuracy remain UNKNOWN. Zero, nonfinite and negative values are missing; nonzero values alone do not certify fish-body depth. Large nonzero anomalies remain in the unchanged raw plane and are exposed through candidate-independent quality statistics.

The manifest supplies actual RGB and depth timestamps and rgb-minus-depth delta_us. Both samples are treated as available only once the pair is obtained; effective acquisition cutoff is max(rgb_timestamp_us,depth_timestamp_us). Fitting uses the frozen observation stream's RGB timestamp in seconds, retained to preserve event/2D timing. DS1 logs the measured 1–2 ms sensor offset and does not claim simultaneous samples or zero-latency deployment.

Whole/core n, valid_fraction, median and MAD are recomputed from raw depth and checked field-for-field against original profiles. Core removes overlap with all current prediction masks and erodes by the unchanged 7×7 kernel. It is an ROI for measurement, not a replacement detection. No whole-to-core fallback, annotation region selection, connected-component filtering, new trigger or detection deletion is applied. The reused core gate is n≥16, fraction≥0.2, positive median, finite nonnegative MAD and max(15,1.4826 MAD)≤60 mm. These are engineering settings, not sensor precision.

Each branch owns DepthState keyed by segment, arm, source generation, public ID and public epoch. The 30-acquisition cache contains raw facts. Invalid/contact/unassigned/group observations cut the active fitted fragment. The latest completed valid fragment can remain a reference within the 30-frame pre-event window, but later observations start a new fragment; no fitting connects across risk. Source/public version changes discard the prior version. A/B snapshot is frozen before first-suspect measurements. Group records and temporary post records are separate. The q measurement enters a restored individual only after an accepted transaction, once, as a new segment.

NE-1 native-first controller, V4 suspect scan, bank references, candidates, q, S0-P publication/local transaction and 2D algorithm are reused. D0 removes the decision depth term; common controller quality/history still uses raw depth, so D0 is not an end-to-end depth-free system. D1 calls the old numeric_choice unmodified. D2 adds the specified WLS/Student-t mixture likelihood-ratio depth term at coefficient 0.25. Actual depth forecast uses the full gap to q; the original 2D term retains its one-second horizon cap.

Prediction imports no provider or event-packet module, creates no model payload, needs no key and has no model/service HTTP. GT labels are opened only by the separate scorer after both complete prediction seals. Numeric and prediction logs are public; raw depth/mask/RGB/GT raster remains local and is listed by real path, bytes, SHA and dependency in the restricted inventory.
