# SLR-1 输出与评分独立复盘

本审计只读第一轮冻结包、最终提案及离线对应关系，没有调用模型、读取凭据或更改第一轮结果。真值仅用于本报告的事后分析，不可写回下一轮模型输入。

## 主要结论

第一轮失败不能归结为 JSON 格式。4 个拒绝都是证据路径错误；其余结构合法。36 对重排中 12 对不一致，只有 1 对是相同物理结论被证据路径合法性拉低，另外 11 对确实改变匹配或是否提交。两处错误在原始与重排中完全一致，说明输出一致性也不是正确性的充分条件。

18 个首分离事件的 Stable 13/18 衡量的是局部公共 ID 连续性。它不是相对全视频固定身份锚点的全局正确率。源码及全部 18 条数据核实：`stable.first_split_correct == (pre_public_ids == post_public_ids)`；每对历史公共 ID 均互异。LLM 的历史原生 mask→当前原生 mask 局部对应关系，和 Stable 的该局部连续性目标是可比较的。没有发现“局部 LLM 对比全局 Stable”的评分混用。

但是，`policy_correct` 只是理想化单次影子重标注：本轮没有执行公共 ID 事务、现有 ID 所有权冲突检查、非目标鱼保护、连续状态更新。因而 1 次正确补救/3 次破坏是**事件级局部提案评价**，不能表述成已经修复/破坏了真实在线跟踪，也不能推导 IDF1/HOTA。

## 重排不一致的真实构成

|类别|全部 36 对中失败数|首分离 18 对中失败数|
|---|---:|---:|
|同一物理决策，仅引用合法性不同|1|0|
|两个 MATCH 的物理分配不同|4|4|
|MATCH 与 WAIT 之间改变|7|4|
|仅 WAIT 中合并组说法不同|0|0|

四个物理匹配变化发生在 1276、8035、10659、12072。原始错而重排对为 1276、8035；两者都错为 10659；原始对而重排错为 12072。首分离另外四个提交/弃权变化是 5939、9518、11488、11900。

原试验每个输入只调用一次，没有“相同请求重复”分支，因此此处证明的是**重复运行且改名改序后的不稳定性**，不能单独将变化归因为排列或编号偏置；随机采样同样可能造成变化。下一轮增加精确重复分支是必要的。

追加只读历史身份检查：106 个实际历史样本中，104 个与事件 pre 时的离线身份一致，2 个匹配身份未知，0 个被现有离线匹配明确反证。未知分别是9518事件中的9301/native2及12072中的12036/native6。没有证据支持把本轮五错统称为“历史身份早已串线”。“几何独立”依然不等于已验证身份，这一输入限制必须保留。

## 一致性保护的能力边界

仅作事后诊断：如果本轮只采纳原始与重排都合法且 MATCH 完全相同的提案，其余保留 Stable，则局部影子策略为 12/18；正确补救仍只有9408，11920与11950两次误改仍然存在。这不能追认为新正式实验或筛选阈值，表明下一轮三次一致规则需要配合更好的证据与非目标身份保护，不能直接视为安全提交许可。

## 对 SLR-2 冻结设计的建议

支持先做同一已暴露18事件上的工程验证：T 为精简数值，V 为相同数值加实际 RGB/mask 裁剪；每事件分别原始、精确重复、匿名重排；合并期另做安全观察。需要逐条落实以下限制：

1. 先核实所选服务模型确实支持并接收到图片，使用带图接口小样；不支持时不把文本描述冒称 V。图片应保留原始 RGB 与可识别的 mask 边界，匿名角色名不含真实身份、帧号或真值颜色编码。重排必须同步打乱图片顺序与角色标签，时序顺序保持。
2. T、V 的数值、候选集合、提示和有限决策空间要逐字段对齐。移除错误缩放的总分并扩大时间跨度属于两组共同修订；只能用 V−T 讨论图片增量，不能用 SLR2−SLR1 全部差值证明图片贡献。
3. 精确重复测运行随机性，重命名重排测综合稳定性。每种只做一次仍不能精确分离排列效应；报告该限制，不额外追分重跑。
4. 预定三次相同合法 MATCH 才采纳，其余保留 Stable；分别列原始、重复、重排、共识效果及格式合法性。至少2个正确补救、零损害、策略≥15/18且 V 比 T 多≥1个正确事件是明确且保守的门，但不是统计泛化证明。
5. 有限候选选项应保留所有非空当前候选，必须能 WAIT，合并假设不强迫一对一；证据 ID 只验证引用存在，不能将引用存在当结论有依据。不要让稀疏候选列表实际引入真值筛选。
6. 事先定义非目标身份冲突：若选择的当前 mask 正由另一非目标公共 ID 占用，记录该冲突及全场影响。未实现事务的一轮可以只评估提案，但报告不能叫完整身份修复成功。
7. 2个并发请求的费用上限要同时预留在途最坏输出、重试及无 usage 失败。所有144响应封存后一次评分；若预算不足中止，明确“不完整、不得晋级”，不要评分部分结果后择优续跑。
8. 保留第一轮及本审计全部记录。新增标注真值只供封存后的评分，不用于构建数值包、裁剪标签、决定参考样本或拼图。
