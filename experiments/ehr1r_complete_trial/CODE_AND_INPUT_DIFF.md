# Frozen EHR-1R-C versus corrected_unsent v6

The source v6 package has **zero** model calls. This run takes its five fixed cases and 25 conditions; it does not treat the seven v5 returns as reusable answers. The review base is `e95f1a776c62028a7f0d6d5e8a48d26b7c7f4f37`.

All 25 ordered image SHA lists are identical to v6. Every q, selected image frame, ROI, named pre/post source frame, and complete hypothesis physical mapping is unchanged. B01-A remains one frame with velocity `UNKNOWN`; B05-Y remains two frames with velocity `UNKNOWN`. All five triggers remain prediction pair-contact proxies and exposed offline controls. There is no GT-based input selection.

The new model text is **not byte-identical** to v6: aggregate UTF-8 text bytes are 4,684,984 → 4,430,379. By arm: E 28,726 → 21,917; H-2D 679,704 → 617,755; each of H-D, repeat and permute 1,325,518 → 1,263,569. `REQUEST_MANIFEST.json` carries each exact new text and image hash.

The projection removes model-visible `SRC-F...-N...`, `frame_local:n:...`, mask hashes and old-anchor lineage. Source references to existing observations resolve to visible named or anonymous facts; absence ranges keep their frame intervals, and the private source ledger retains native handles. Anonymous event `fact_id` is newly randomized within each frame. The redundant old `local_token` table column is removed; each image token explicitly names its visible `fact_id`, and role tokens name their endpoint position fact. The model does not receive the private `(frame,native)` bridge or new tracker priors.

E keeps only the q-facing endpoint observation in each segment and drops `fragment_id`, `first_position_fact_id`, `last_position_fact_id`, history-derived velocity and intervals. **The frozen projection missed `anchor_frame` in each X/Y post segment: all five E requests expose an earlier first-clean frame after deleting that observation. This violates endpoint-only scope and caused the partial engineering stop.** The false-positive pre-call gate and the later regression are preserved separately. H-D preserves all ten v6 anonymous depth/quality columns; H-2D omits depth, while the pre/post and anonymous source facts stay in the private audit. `entry_side` is `NOT_ESTIMATED` because no boundary crossing estimator ran. The existing UNKNOWN velocity and physical entry/reappearance states are preserved. H-D-REPEAT has identical text and images to H-D; H-D-PERMUTE changes labels/order but preserves physical alternatives.

The scorer now binds the actual A/B/X/Y endpoints to GT **after** the response seal and stores the correct complete physical mapping. Each response label maps through that request's candidate dictionary. Negative protection requires returned/stop/parseable/usable/scoreable before correct or legal DEFER can count. Technical validity, recovery, negatives, paired history gain and semantic citation review are reported separately. The full same-information numerical comparator is unavailable; inherited N-H2D/N-HD consume endpoint history only.
