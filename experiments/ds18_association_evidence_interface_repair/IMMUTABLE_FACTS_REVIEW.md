# DS18 只读证书加速独立审查

结论：常规操作与序列化等价检查 PASS。模型调用、费用及 GT/RGB/修复深度读取均为 0。

- 完整普通负例测试 13 项通过；普通 JSON 仍执行完整签名和语义校验。
- 原生 JSON 字典/列表形状、canonical digest 和数据值不变；copy/deepcopy 共享已验证的只读事实，producer/controller 使用同一模块。普通 root/child/list 写入、update、append 均拒绝。
- 实际运行代码的显式 dict/list/object 基类写入仅在构造阶段或完整验证后赋可信标志；没有发现验证后修改证书的调用点。详见 JSON 中实际文件 SHA 和逐调用位置。
- 真实开发 50 帧 immutable 前缀独立来源/EMA 检查通过：582 次原始 whole 递推回查，自动 accepted 动作 0 次。零动作仅验证该前缀 EMA，不能宣称已验证全段动作或方法收益。

## 明确边界

这不是同进程恶意 Python 代码隔离。保留 JSON 原生 dict/list 形状的子类无法阻止显式 dict.__setitem__ 等基类绕行写入；O(1) 可信路径不会检查这种故意破坏。审查仅在重新从 JSON 构造的一次性合成对象上验证了这一边界，未修改真实输入或分支共享证书。绕行后的对象再次序列化为普通 JSON 时，完整校验会拒绝。主实验已接受常规操作边界并冻结实际调用代码；旧审计、来源证明与结果保留。
