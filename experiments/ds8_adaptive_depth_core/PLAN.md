# DS8：自适应内部采样的单变量完整试验

## 来源与动机

DS7五枝1471帧已封存。P2与原生逐帧一致，未提点。其19个q中，14个post不可用；13个固定7×7独占腐蚀core不足16个像素，12个即使不排除重叠仍不足16。原整mask有真实有效深度，补孔不能修复采样区几何为空。本轮测试由预测mask宽度确定内部区，禁止按GT选择区域或放宽关联门槛。

## 唯一新变量

对当前SAM3 mask先排除重叠像素，再逐8连通片计算真实L2距离变换；每片取distance>=max(1.5,min(3.0,0.5*max_distance))。所有片保留，边界补零，不填洞、不选择最大片。阈值单位为当前640×360像素，不由深度、GT或案例答案确定。窄片仍可能为空，保持UNKNOWN。

实测与模型推断分层，实测合格优先，否则推断单独使用。点数16、比例0.2、MAD尺度60mm、推断噪声假定60mm、depth权重0.25和最小候选gap log9全部保持DS7原值。core.mad中的推断噪声适配代理与actual MAD明确分列。所有实际常数来自代码，CONFIG同步说明。
