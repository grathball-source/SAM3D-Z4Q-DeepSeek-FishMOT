# DS21 frozen diagnostic plan

## Question

Does existing, causally available depth evidence add discrimination to the original Z4Q's actual association decisions without suppressing its successful recoveries? Improving bookkeeping alone is not a performance claim.

The original D1 already uses whole-depth residual/MAD, motion, competing partners and natural five-confirmation acceptance. Birth already uses core, whole counterevidence, survivor comparisons and native continuity. Recomputing these same summaries is not new information. Potentially additional facts are independent-source population, shared-sample contamination, observed layer distributions and local measurement quality. Layer-to-physical-fish ownership remains UNKNOWN.

## Decision boundary

A source-quality pass does not certify fish identity. A missing source/reference is a limitation of this diagnostic. Better feature availability does not prove better candidate discrimination. Vetoing wrong actions while also losing correct actions cannot be called an improvement without a separate genuine own-state replay. Existing original scalar summaries and weak order probabilities cannot be credited as new depth evidence.

After all actions are reviewed, state whether any narrowly defined additional observation has sufficient diagnostic support for a subsequent minimal trial, or whether the current depth representation remains insufficient. Plan only one next action based on the complete census. Do not automatically run another full multi-arm experiment, change thresholds, prepare model calls, or turn this exposed diagnostic into a generalization claim.
