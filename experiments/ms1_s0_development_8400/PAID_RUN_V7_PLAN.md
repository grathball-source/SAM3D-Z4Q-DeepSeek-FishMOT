# MS1-S0 开发集真实调用冻结计划

授权：用户在扫描复盘完成后明确指示“调用吧，无需考虑用量”。本计划固定模型工作量，不设美元停止线：开发集最早 8 个合并确认事件，每个最多一次 M 和一次 S0，正式推理 HTTP 最多 16 次；不做额外 smoke、语义重试、投票或择优。官方 `deepseek-flash`，预测掩码几何 PNG 通过官方 Files API 上传；不发送 RGB、GT raster、凭据或本地 native/public 对应表。请求由同一 SYSTEM、原 MS1 提示词和可追溯事实生成。

固定事件顺序：F1152、F3078、F3863、F4057、F4485、F4519、F5399、F5927。来自此前无 API 全段的确认时刻顺序，与 GT 和模型返回无关。若真实分支中某个事件不再合格，不以 F7997 或其他事件补位。M 在该事件合并确认帧调用，只产生可推翻假设；S0 在该分支首次出现两个足量候选时调用，X/Y 各只有当前帧一个 post 观测，不读取 q 之后的帧。合并观察留作 group 与匿名证据，进入前参考不跨风险拼接。

启动前检查 `PREFLIGHT_V7.json`：16 个无 API 控制请求包、图像帧和事实引用均不越过各自截止帧；最大估计输入 381466 tokens。S0 实际文本中才加入已收到的 M 假设；结构化投影上界留有 30000 tokens 余量，输入门槛为官方 100 万上下文减 65536 最大输出。不能为通过门槛删证据。`CONFIG_V7.json` 只把本轮授权与固定事件写成配置；旧 v6 及更早 seal、响应和评分只读。

发送前冻结代码、源、预检与门槛。Files 上传和推理分别留 START/END 或 UNKNOWN；HTTP 未知不重试。普通停止先不再发送新 START，同步收齐唯一在途请求后继续完整段。无效/DEFER 只回退该事件到冻结数值关联；数值也不能辨别时回退同帧因果 B0 状态。先 stage/commit，才首次发布 q 帧。完整 8400 帧预测封存后，由 `score.py` 独立计算 IDF1/HOTA/AssA/IDSW/FP/FN，由 `postseal_event.py` 与 `model_event_audit_v7.py` 分列模型原始选择、有效性、物理参考正确性、实际提交和不可评分。

本轮不训练、不改 Z4Q 主体、不读取未曝光 test GT、不重启 DAA、不覆盖旧实验、不自动进入后续阶段。结果好坏均记录并提交 main。
