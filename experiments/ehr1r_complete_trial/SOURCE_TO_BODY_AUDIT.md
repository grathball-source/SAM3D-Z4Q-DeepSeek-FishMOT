# Source to final body audit

The existing v6 `DEPTH_INPUT_AUDIT.json` checks 727 unique frames and 4332 mask profiles against raw HDF5 arrays and predicted masks. EHR-1R-C independently reread the predicted observation and depth feature streams for 813 case×frame positions (727 unique due B04/B05 overlap) and 4848 source observations. It checked every named pre/post position, cleanliness and depth profile, every anonymous event observation's position/risk and all ten anonymous depth/quality values against those streams. It checked that the q limit, reference segment frames, image SHA, ROI/time, endpoint box and image token lineage agree with the frozen source. A rendered mask token can occupy a clipped region inside a larger source observation box; the check requires the token's private lineage match and region overlap within the ROI rather than equality of bounding boxes.

The exact five case counts are in `public/SOURCE_TO_BODY_AUDIT.json`. `public/REQUEST_MANIFEST.json` hashes all 25 projected logical texts and image order. `public/BODY_GATE.json` records the independent final check: each actual serialized Files API body equals the sealed logical text plus uploaded image IDs in that order, under the frozen model, thinking and JSON settings. Private provider IDs and bodies are never published. `public/REQUESTS_SEALED.json` binds the 25 actual payload hashes to the code/input lock before formal inference. **These gates missed stale `anchor_frame` metadata in E X/Y post segments.** `public/POSTSTOP_SOURCE_FAILURE_AUDIT.json` supersedes their E endpoint-only conclusion without modifying them or the sent payloads.

The B01 source→role→condition→serialized body→synthetic response→scorer fixture is marked `TEST_FIXTURE_NO_MODEL_CALL` in `public/END_TO_END_ACCEPTANCE.json`. The fixture exercises H1, H2, DEFER, invalid citations, unscoreable reference, truncation, candidate permutation, U mapping, invalid negatives, q-after-frame and logical/body/START/response tampering. This tests the engineering chain, not the model's ability.
