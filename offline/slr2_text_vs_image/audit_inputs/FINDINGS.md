# SLR-1 输入与确定性对照独立复盘

2026-09-20。本审计只读已完成的 `engineering_r3` 源码、封存证据包、私有映射及评分摘要；未读取密钥、调用 API、访问服务器或修改旧实验。复算入口 `audit.py`，逐查询数据与源文件 SHA256 见 `AUDIT_DETAILS.json`。以下统计是故障定位，不作为新轮调参集上的泛化结果。

## 结论

SLR-1 支持“当前完整方案不可晋级”，但弱 B1 并不能有效回答“LLM 是否优于有竞争力的确定性关联”。B1 首分离 18 例仅 9 例提案、1 例正确、8 例错误；保留原结果的策略为 8/18，明显低于 Z4Q 的 13/18。LLM 的 9 个正确提案优于此 B1，不足以证明语言推理贡献。需保留 Z4Q 为主对照，并区分输入表达修复与新增传感信息。

## 已复现的实现缺陷

`build_packets.py:115–117` 对非独立参考将所有模态权重乘 0.25，随后以权重和归一化：

`sum(cost * (0.25 * weight)) / sum(0.25 * weight) == sum(cost * weight) / sum(weight)`。

因此“几何风险降低匹配信任”的设计没有体现在 B1 分数或接受门槛中。424 条边全部复算，最大分数差为 0。72 个查询历史项中 12 项使用 fallback 风险历史（每个事件的两种查询重复使用同一参考，故不是 12 个独立事件）。LLM 仍可自行读取风险字段，因此不能把该缺陷直接当作 LLM 错误的原因。

下一轮不要凭旧答案寻找更好的风险倍率。应明确把“参考质量”和“模态内部相对权重”分开，保留独立质量字段；若要用于接受规则，预先定义单独质量条件并进行与真值无关的语义回归。直接取消无效的倍率也是诚实修复，不能声称它提高了安全性。

## 历史与运动证据薄弱

参考选择是 pre 前最后三个符合条件的观测，通常是相邻帧；120 帧搜索窗并不等于使用了 120 帧运动历史。

| 量 | 中位数 | 最大值 |
|---|---:|---:|
| 最新参考距查询时间 | 2.166 s | 9.663 s |
| 运动估计首尾时间跨度 | 0.067 s | 0.234 s |
| 外推时长 / 估计跨度 | 30.3 倍 | 218.1 倍 |
| 预测位移 | 68.3 px | 564.4 px |

72 个历史项全部有参考，62 项超过 1 s、16 项超过 5 s；13 项外推中心落在 640×360 图像外。短时掩码中心噪声、姿态变化与鱼转向会经长时外推放大。当前程序没有速度稳定性、拟合残差、预测区域不确定性，只给 `1/(1+age)` 权重。此为建模限制而非未来泄露；不能把运动残差当精确关联证据。

history 在 pre 冻结，recent 最多 5 个均匀采样时刻；recent 没有 HSV 外观或与各历史的成对代价。因而原始数值包确实有交互经过，但“长时间可靠记忆与详细交互轨迹”尚未实现。原生历史归属也明确未核验，干净几何不能修复已错身份。

## B1 的尺度和覆盖问题

424 条边中 396 条有三模态、26 条有两模态，仅 2 条只一模态。18 个首分离查询均有合法一对一候选组合。9 次 WAIT 中 4 次因绝对成本、5 次因最优/次优间隔，不是整包缺深度造成。

全部边代价中位数：外观 9.27、深度 0.726、运动 1.205。外观除以旧任务固定尺度 `0.010273070237761233`、权重固定为 1；深度权重为有效比例，运动随年龄下降。这样较老参考的 HSV 差异常常主导分数。该数值不是算错，但尚无证据说明旧尺度适用于数秒间隔与照明变化。不能用这 18 个答案重估一个好看的尺度后再声称独立验证。

B1 只读取每边成本、模态数以及当前 mask 非空条件。它未利用 recent 交互、当前碎片比例、邻接关系或合并状态；也永远不能输出 POSSIBLE_MERGE。212 个当前描述符中，134 个存在邻接，20 个最大连通域占比小于 0.9；这些风险对 B1 接受逻辑不起作用。合并期 B1 仍给出 8/18 个完整双目标匹配。它拥有同一包的访问权，不能据此说它实际使用了相同上下文推理。

## 输入表达与公平性

1. 当前有 5–6 个候选，全部保留，是正确的；只保留两条目标历史意味着附近第三条鱼有当前观测，却没有等量历史归属证据。
2. `recent` 给 focal 旧轨迹保留 `native_lineage_focal_track`，但 `current` 没有显式同源关系。recent 的 t=0 与 current 使用不同别名；模型只能通过相同几何自行连接。同源不是身份真值，但应明确序列化为不可信的观测谱系，并一致提供给全部方法，避免模型承担无关的别名/数组连接工作。
3. 每个 recent 时刻重新生成观测别名，非 focal 观测没有跨时刻持续匿名谱系。因此第三条鱼的跨时序跟踪特别弱。对此做修复是增加可用元数据连接，须单列为表达修复，不能与原包声称逐字节同输入。
4. 包的紧凑 JSON 长度中位数 27,215 字符（22,692–30,248）。48 维 HSV 向量在多份历史/当前观测重复出现，模型同时又获得程序计算的相似度；序列化 full precision 数字有明显冗余。紧凑化可降低处理成本与引用负担，但若删向量/原值，就应称“同来源证据的摘要”，不能称严格无损同输入。
5. 输出 JSON Pointer 是数组位置引用；重排后相同证据指针需要变化。结构合法性只证明字段存在，不证明支持结论。用枚举的合法假设 ID、证据 ID 与程序生成物理映射，可减少幻造标识符/无效路径，但语义正确性必须另评。
6. pre、目标二元组和合并/分离时刻都是已暴露的离线筛选；本轮做得较严格的 GT 隔离没有消除 oracle 条件。下一轮沿用这些事件只能报告机制开发，不是独立新测试。

## 下一轮建议：先修表达与决策合同，图像单列

建议优先小规模、冻结的 SLR-2 数值实验：保留全候选与全部有效一对一假设，不按已知答案剪候选；用程序枚举 5–6 个候选的全部 20–30 个完整匹配、单候选合并假设和 WAIT。模型只选择一个合法假设并引用显式证据项。不要只枚举 B1 最优两种：B1 的 8 次错误表明其排序可能将真值提前排除。

紧凑输入提供：每个历史的年龄、跨度、质量、原始可解释测量；各候选碎片/邻接与深度质量；全部成对深度差、外观距离、运动残差及预测可靠性；显式匿名谱系。历史仍声明未核验。需要保留原始模型输入作为归档，并把表示变化写清楚。

最少包含：Z4Q 保留策略、冻结旧 B1、同一新摘要的确定性假设选择、LLM 假设选择；匿名 ID/候选顺序/假设顺序变化时同时变换映射。保持旧数据为开发集，阈值和提示只在新调用前冻结。强制区分明确正确提案、错误提案、实际修复、原正确被破坏和弃权保留。双视图不一致就弃权的安全策略需预先冻结并单列；不能事后从两个答案挑对的。

图像分支有潜在必要性：HSV 直方图没有鱼体形状、斑纹空间分布或多鱼边界信息；模型无法从数值凭空恢复这些。然而加图属于新增信息，当前首轮失败不能归因于“没看图”而跳过数值工程问题。若并行探索，必须作为单独多模态臂，并先验证所选实际 API 支持图像；不得假定 `deepseek-flash` 可看图。其成败不能直接与同输入语言收益混算。此审计未做 API 能力验证。

即使 SLR-2 更好，也只能说明在已暴露事件上的工程改进。自动事件发现、独立新视频、连续跟踪、SAM/Z4Q 回写都需要后续阶段；本轮不自动进入闭环。
