# Frozen protocol

- Cases and query cutoffs are the AO1 B01–B05 windows. No GT, old answer, or model result selects a trigger, anchor, or easier case. The trigger audit is an observed pair-contact proxy; each case is separately labelled if it lacks this predicted contact.
- A/B are **new EHR-1R roles**: the last contiguous clean native-mask island before the fixed trigger, truncated to at most 31 frames. A risk gap never joins islands. `old_to_new_reference` records whether each original AO1 anchor belongs to that island; otherwise old-role equivalence is unresolved. X/Y are the q-ending clean island, at most 15 frames, with insufficient motion samples marked UNKNOWN.
- All remaining predicted observations between the earliest input frame and q are frame-local anonymous event records, including risk frames and clean islands after an identity break. The complete verbose facts are sealed in `EPISODE_FACTS.json`; requests use a column-encoded event table containing each anonymous record. A token or native handle through risk does not certify identity.
- E sends endpoint snapshots only. H-2D sends the qualified fragments and full anonymous event table without depth. H-D adds synchronized raw depth profiles and quality. H-D-REPEAT has exactly the H-D request body; H-D-PERMUTE changes candidate names/order only.
- Each sent image records its source frame and time, original ROI, dimensions, full-frame-to-image coordinate transform, and actual local token/bounding region. Endpoint A/B/X/Y boxes are drawn on the actual RGB crop. Middle images are frozen M2 mask-token renderings; they convey anonymous morphology, not a path through risk.
- The official `deepseek-flash` Files API route, high reasoning, JSON response, one concurrent call, and 65,536 max output tokens are retained. Up to 25 formal calls plus one smoke and USD 3 apply only to this batch. All 25 logical packets and their budget are gated before any formal answer. No semantic retries.
- Score only after the full response seal. Rebind each **new** reference and q endpoint through the exposed relation timeline; if a role is nonunique or the true mapping lies outside two candidates, mark the case unscorable. The old score key is compared afterward, never assumed to be the new answer.
- N-H2D/N-HD use the same qualified pre/post source fragments, with all-four-edge depth availability or symmetric 2D fallback. They are endpoint-history references, not same-information full-event comparators. VLM necessity stays NOT_TESTED. No tracker update, HOTA/IDF1, DAA, training, or E2 follows automatically.
