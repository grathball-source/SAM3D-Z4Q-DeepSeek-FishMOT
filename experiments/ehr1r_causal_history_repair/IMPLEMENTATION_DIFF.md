# Repair relative to frozen EHR-1

1. `contract.py` independently rereads source observations and rejects every old identity segment that crosses contact, zero area, absence, or a frame gap. The real old B01/B02/B04-A packets fail before new preparation.
2. `prepare.py` creates local clean fragments and anonymous risk/event records. It does not filter risky frames and reconnect the clean samples on either side. B01 receives new pre-risk reference roles; their equivalence to old contact-frame roles is explicitly unresolved.
3. The post window is split by the same source rule. Motion uses only the q-connected clean island, with a 0.5-second, three-distinct-time fit requirement. Position and depth belong to that same island. Event intervals, handle return, pair-joint cleanliness, and relative motion are separate fields with fact IDs and source references.
4. Every new depth frame is checked against raw HDF5, frame time, original RGB, and source mask profiles. In v5, **named pre/post depth** had availability, synchronization, valid fractions, core counts, MAD, and risk, but anonymous event depth exposed only median and valid fraction. `SOURCE_FAILURE_AUDIT.json` proves this omission across all 15 H-D logical packets. The current `prepare.py` and `audit.py` repair and reject that omission in `corrected_unsent/`; that package was not sent.
5. `numeric.py` removes single-edge `depth_cost or 0`. It applies depth only when all four edges are comparable; otherwise both hypotheses use geometry and the result says `DEPTH_UNAVAILABLE_FALLBACK`.
6. Endpoint role labels are bound to actual RGB crop boxes, with a fixed ROI transform. Intermediate mask tokens remain anonymous. E excludes the old-to-new lineage map and event-derived fields; H-2D and H-D differ only by depth data.
7. `audit.py` checks every included identity observation against source rows and every anonymous observation against the source population. The v5 audit missed anonymous depth-quality completeness; the current audit explicitly checks all required model-visible fields. The actual v5 sender required the plan digest and its then-current gate. The response path stopped at a partial seal; there is no full trial score.

The fact-comparison task, model route, candidate pair, q, case list, and response schema remain the frozen EHR-1 definitions. This repair changes the reference meaning for roles whose old anchors crossed risk; `CASE_SCORE_BINDING.json` checks that meaning after the partial seal without scoring the invalid trial.
